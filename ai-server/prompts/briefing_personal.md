# 쓸 것
1. warmup_questions: 수업 시작 5분 동안 학생에게 **한국어로** 물어볼 질문 2~3개.
   학생의 관심사·목표·선생님 메모에서 소재를 고르고, 학생 수준에서 대답할 수 있게 아주 쉽게 씁니다.
   예: "주말에 한국 드라마 봤어요?"
2. practice_activity: 수업 후반 12분 동안 할 말하기 활동 1개.
   학생의 목표·관심사에 맞는 상황을 정하고, "상황 / 학생 역할 / 써야 할 표현(이번 새 문법 포함)"을 한 문단으로 씁니다.
   예: "상황: 서울 카페에서 주문하기 / 학생: 손님, 선생님: 점원 / 표현: 커피를 주세요, 저도 ~를 좋아합니다"
3. tips: 이 학생에게 맞춘 수업 운영 팁 3개. 설명을 어느 언어로 얼마나 쉽게 할지, 학생 성격·메모에 맞춘 진행 방식, 관심사를 대화 소재로 어떻게 쓸지처럼 구체적으로 씁니다.
   **문법 규칙이나 문법 설명은 쓰지 마세요.** 문법 설명은 교원용 지침서와 검수된 자료에서 따로 가져옵니다.
   새 한국어 예문도 만들지 마세요. 예문은 교재와 세종학당 자료에서 가져옵니다.
