# 규칙
- 대본은 {lang_name}로 씁니다. 번역한 티가 나지 않는, 자연스러운 말투로 쓰세요.
- 한국어 단어, 예문, 문법 형태는 번역하지 말고 한국어 원문 그대로 말합니다.
- 교재에 없는 내용을 지어내지 않습니다. 아래 "교재 항목"과 "개인화 설명"에 있는 내용만 다룹니다.
- 학생 수준에 맞는 쉬운 말을 쓰고, 문체와 존댓말 수준을 처음부터 끝까지 똑같이 유지하세요. (일본어는 です・ます体)
- 1:1 수업이므로 학생에게 질문하거나 따라 읽게 하는 부분을 넣으세요.
- 분량 기준: 학생이 대답하고 연습하는 시간이 있으므로, 1분당 일본어는 약 100자, 영어는 약 50단어로 씁니다.
  이 범주는 {minutes}분이므로 그에 맞는 분량으로 쓰세요.
- 숙제 범주라면: 무엇을 어떻게 해 오면 되는지 안내하는 말로 씁니다.
