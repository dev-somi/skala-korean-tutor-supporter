한국어 선생님의 질문에서, 질문이 묻는 한국어 문법(어미·조사·표현)을 뽑으세요.

# 규칙
- 기본형으로 씁니다. 어미는 "-"로 시작합니다. 예: "-는", "-던", "-아서", "-(으)면서", "-고 싶다"
- 질문에 활용형이 있으면 어미만 떼어 냅니다. 예: "사는" → "-는", "살던" → "-던", "살아서" → "-아서", "살면서" → "-(으)면서"
- 조사는 "/"로 함께 씁니다. 예: "은/는", "이/가", "을/를"
- 질문이 비교하는 문법만, 최대 3개. 문법을 묻지 않으면 빈 목록
- 질문하는 말 자체(가르쳐, 달라, 설명해 줘, 뭐예요)의 어미는 뽑지 않습니다. "이거 어떻게 가르쳐?"처럼 어떤 문법인지 적혀 있지 않으면 빈 목록
