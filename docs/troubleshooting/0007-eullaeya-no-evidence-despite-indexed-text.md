# TS-0007: "-을래야"가 색인 글에 3번 나오는데 "교재 근거 없음"이었다
- 날짜: 2026-10-22
- 관련 모듈: `ai-server/app/agent/grammar_qa.py`, `ai-server/app/rag/index.py`
- 관련 ADR: [기술 ADR-0044](../adr/0044-grammar-evidence-text-fallback.md), [기획 ADR-0036](../planning-adr/0036-ai-explanation-when-no-textbook-evidence.md)

## 증상
"-을래야 어떻게 설명해?"가 교재 근거 없음으로 나오고, AI 설명(qwen3:8b)이 틀렸다.

```
usage: 원하는 일을 하려면 어떤 조건이 필요한지 물어볼 때 쓴다
examples: 공부를 해야겠다는 건, 빨리 시작을 해야 라이브러리에 가야 해요. …
```

## 원인
`grep -c "을래야" data/rag/index/parents.jsonl` → 3. 색인에는 설명이 있었다.
1. 교재는 표준어 `-(으)려야`로 가르쳐서 teaches 태그가 `-려야`다. 표준 등급 목록의 `-을래야`(4급)는 따로 떨어진 항목이라 관련형 연결(ADR-0037)도 없다.
2. OCR이 닫는 따옴표를 놓쳐 `'-을래야 로`가 됐고, mentions 태그가 안 붙었다.
3. 의미 검색 경로는 mentions에 그 형태가 있는 구역만 남겨서 전부 버렸다.
- 처음에는 "책을 더 색인해야 하나" 싶었지만, 96권 28,089 child가 이미 임베딩돼 있었다. 모자란 건 자료가 아니라 검색 경로였다.

## 시도한 것
| 시도 | 결과 |
|---|---|
| 색인 글에서 "을래야" grep | 3구역 (4B 익힘책 지침서 16과, 4B 매뉴얼 16과, 4B 익힘책 17과) |
| `find_by_text`로 찾은 자리 줄부터 인용 | 근거는 붙었지만 같은 쪽의 "-는 통에" 글이 대부분이라 답이 "-을래야는 발음 방식"으로 나옴 |
| 찾은 자리 앞 450자부터 인용 + "이 문법 부분만" 표시 | "의도가 있지만 결국 할 수 없는 상황을 나타낼 때 쓴다" (교재대로) |

## 해결
- `rag/index.py` `find_by_text`: 본문 정규식으로 구역을 찾고, 여러 개면 벡터 점수로 순서를 정한다.
- `grammar_qa.py` `text_pattern`·`text_excerpt`: 태그·의미 검색으로 못 찾았을 때만 붙임표·따옴표 뒤에 적힌 형태를 찾고, 앞 450자부터 인용한다.
- 테스트: `test_untagged_section_is_found_by_text`.

## 배운 점 / 다음에 주의할 것
- "근거 없음"이 나오면 먼저 색인 글을 grep해 본다. 태그에 없다고 자료에 없는 게 아니다.
- 한 쪽에 문법 여러 개가 같이 있는 교재(익힘책 지침서, 매뉴얼)는 찾은 줄만 잘라 인용하면 본 설명이 빠진다.
