# TS-0001: 문법 질문이 질문에 없던 -어/아서를 "근거 없음"으로 돌려줬다
- 날짜: 2026-10-21
- 관련 모듈: `ai-server/app/rag/forms.py`, `ai-server/app/agent/grammar_qa.py`, `ai-server/prompts/grammar_forms.md`, `frontend/src/api/mock/`
- 관련 ADR: [ADR-0025](../adr/0025-form-key-tags-and-merged-editions.md), [ADR-0027](../adr/0027-chat-frontend-mock-stream.md)

## 증상
`POST /grammar-qa`에 두 질문을 보냈다 (student_level=1).

```
"이거 어떻게 가르쳐?"     → forms: [{"form":"-어/아서","key":"-어","grounded":false}], ai_note: "근거 자료 없음"
"-어/아서 어떻게 가르쳐?" → forms: [{"form":"-어","key":"-어","grounded":false}],     ai_note: "근거 자료 없음"
```

핸드북에 「-아서/-어서/-여서」가 있는데 근거 없음이 나오고, 요점도 엉뚱했다. mock fixture `ungrounded.json`이 바로 이 잘못된 응답을 저장한 것이었다.

## 원인
세 가지가 겹쳤다.
1. **줄임 표기를 몰랐다.** `form_keys("-어/아서")`가 `/`로 나눠 `-어`와 `아서`로 만들었다. `아서`는 `-`가 없어서 버려지고 `-어`(반말 어미)만 남았다. 교재 제목은 `-아서/-어서`처럼 다 적어서 지금까지 드러나지 않았다.
2. **질문에서 뽑을 때도 잘렸다.** `HYPHEN_FORM`은 `-어`까지만, `SLASH_FORM`은 `어/아서`를 따로 잡았다.
3. **형태가 없는 질문에서 LLM이 형태를 지어냈다.** "이거 어떻게 가르쳐?"에는 형태가 없어서 저가 모델로 넘어갔다. 모델이 질문 동사 '가르쳐'의 어미를 `-어/아서`로 돌려줬다. 권위 게이트는 키가 목록에 있는지만 봐서 통과했다.

처음에는 RAG 색인(태그) 문제라고 짐작했다. 그런데 `-아서랑 -(으)니까`는 같은 색인에서 제대로 나와서 형태 키 쪽을 의심했다.

## 시도한 것
| 시도 | 결과 |
|---|---|
| Spring 경로(`/api/chat/stream`)로 같은 질문 | 라우터가 `general`로 보내서 RAG를 아예 안 탐. 버그가 가려졌을 뿐이다 |
| ai-server에 직접 요청 | 재현됨. 키가 `-어`인 것을 확인 |
| `form_keys`, `forms_in_text`를 하나씩 찍어 봄 | `-어/아서` → `{-어, 아서}`, 질문 → `['-어', '어/아서']` |

## 해결
- `forms.py`: `SHORTHAND`로 `-아/어서`·`-아/어/여서`·`-았/었어요`를 먼저 `-아서/-어서` 꼴로 펼친다.
- `grammar_qa.py`: `HYPHEN_FORM`이 `-어/아서`를 통째로 잡는다. `SLASH_FORM`은 `-` 뒤를 잡지 않는다. 뒤 낱말("어떻게")이 키를 바꾸지 않으면 표시 이름에서 뗀다.
- `grammar_qa.py` `in_question`: LLM이 뽑은 형태의 글자가 질문 낱말 속(첫 글자 뒤)에 없으면 버린다. "가르쳐"에서 `-어/아서`는 빠지고, "사는"의 `-는`, "가서"의 `-아서`는 남는다.
- `prompts/grammar_forms.md`: 질문하는 말 자체의 어미는 뽑지 말라는 규칙을 더했다.
- 테스트 3개 추가 (`tests/test_grammar_qa.py`, 99 passed).
- mock: `ungrounded.json`을 실제 근거 없음 사례(`-더라고요 어떻게 설명해?`, 5급)로 다시 찍었다. "어떻게 가르쳐"는 "형태 못 찾음" 시나리오로 옮겼다.

고친 뒤 실제 응답:
```
"-어/아서 어떻게 가르쳐?" → -어/아서 (key -어서, 1급, grounded)
"이거 어떻게 가르쳐?"     → forms [] , "어떤 문법을 묻는지 찾지 못했어요…"
```

## 배운 점 / 다음에 주의할 것
- 선생님은 교재와 달리 `-아/어서`처럼 줄여 쓴다. 형태 키 테스트에는 교재 제목뿐 아니라 사람이 치는 표기도 넣는다.
- fixture는 "실제 응답"이라도 버그 응답일 수 있다. 저장할 때 내용이 맞는지 한 번 본다.
- 남은 문제: `-거든요`가 `-거든`(3급, 조건)으로 잘려서 다른 문법의 근거가 붙는다. `_match_part`가 뒤에서 한 글자씩 떼다가 먼저 맞는 짧은 키를 고르기 때문이다.
