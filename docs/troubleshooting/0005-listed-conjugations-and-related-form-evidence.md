# TS-0005: "너라면, 너라서, 너니까"는 형태를 못 찾았고, "-라면, -라서"는 교재 근거가 없다고 나왔다
- 날짜: 2026-10-22
- 관련 모듈: `ai-server/app/agent/grammar_qa.py`
- 관련 ADR: [기술 ADR-0037](../adr/0037-listed-conjugations-and-head-form-evidence.md)

## 증상
챗봇 문법 질문 두 개가 실패했다.

```
너라면, 너라서, 너니까, 너거나 차이 설명해줘
→ 어떤 문법을 묻는지 찾지 못했어요. '-아서', '은/는'처럼 형태를 적어서 다시 물어봐 주세요.

-라면, -라서 차이 설명해줘
→ -라면 표준 4급 조건 · 교재 근거 없음 / -라서 표준 1급 · 교재 근거 없음
   AI 보충 · 검수 필요
   근거에 없는 예문이 들어 있어 뺀 내용: 예: '공부를 많이 하면 점수는 높아진다'는 -라면으로, …
```

## 원인
1. 첫 질문에는 `-`·`/`·따옴표가 없어서 코드(`forms_in_text`)가 아무것도 못 뽑고 fast 모델로 넘어갔다. 같은 질문으로 fast 모델을 두 번 돌려 보니 두 번 다 `{'forms': ['-는', '-는', '-는', '-는']}`였다. `in_question` 게이트가 이 결과를 맞게 버려서 남은 형태가 0개가 됐다. 게이트는 제대로 돌았고, 모델이 형태를 엉뚱하게 지어낸 것이다.
2. 두 번째 질문은 표준 목록에서 맞았다(`-라서` → -어서 항목의 관련형, `-라면` → -는다면 항목의 관련형). 하지만 근거는 `-라서`·`-라면` 키로만 찾았는데, 교재 teaches 태그는 대표형 제목(`-어서`, `-는다면`)에 붙어 있었다. `rag_index.known_keys()`에 `-라서`·`-라면`이 없었다.
- 처음에는 "니까"가 조사인지 의심했다. 하지만 "너니까"는 너 + 이(다) + -니까이고 끝부분은 연결어미다. 표준 목록에도 -으니까(1급)의 관련형으로 `-니까`가 있다.
- 빠진 예문('하면', '하므로')은 -라면/-라서 예문도 아니었다. 예문 게이트가 맞게 막은 것이다.

## 시도한 것
| 시도 | 결과 |
|---|---|
| fast 모델(grammar_forms)에 그대로 묻기 | 두 번 다 `-는` ×4 → 게이트에서 버려짐 |
| 표준 목록에서 `-라면`·`-라서` 키 조회 | 등급은 나옴 (-는다면 4급, -어서 1급) |
| 색인 known_keys에서 같은 키 조회 | 없음 → 근거 0건 |

## 해결
- `listed_endings`: 쉼표·띄어쓰기로 나열한 낱말의 같은 앞부분을 떼고, 남은 끝에 `-`를 붙여 맞춘다. 끝이 "이"로 시작하면 '이다'의 '이'를 떼고 다시 맞춘다. `forms_in_text`에 더했다.
- `match_forms`: 표준 항목 표제 형태의 키를 `search_keys`에 더하고, `collect_evidence`가 이 키로 찾게 했다. 대표형이 다르면 근거 자료에 "관련형"이라고 적는다.
- `MAX_FORMS` 3 → 4.
- 확인: 같은 질문이 LLM 없이 -라면(4급)·-라서(1급)·-니까(1급)·-거나(2급)로 맞고, 넷 다 교재 근거가 붙는다. `tests/test_grammar_qa.py`에 테스트 2개를 더했다.

## 배운 점 / 다음에 주의할 것
- 없는 데서 형태를 지어내는 일은 fast 모델이 잘 틀린다. 규칙으로 정할 수 있는 모양(같은 앞부분 + 다른 끝)은 코드로 먼저 처리한다.
- 표준 목록에 맞는 것과 교재 색인에 맞는 것은 다르다. 등급이 나와도 근거 키는 따로 확인해야 한다.
- 같은 날 다시 막힘: "너라면 너라서 너니까 너거나"(쉼표 없이 띄어쓰기)는 처음 규칙이 쉼표만 봐서 못 잡았다. 띄어쓰기도 나열로 보고, 끝이 2개 이상 맞는 묶음만 쓰게 했다. "먹어서랑"처럼 끝에 붙은 조사도 떼어 본다.
- 같은 날 세 번째: "라면이랑 니까를 일본어로 어떻게 설명할까?"는 하이픈도 나열도 없어서 코드가 못 뽑았고, fast 모델(qwen3:8b)은 두 번 다 `{'forms': []}`를 냈다. "A랑 B" 비교 모양을 코드로 푸는 `paired_forms`를 더했다 (붙은 조사를 떼고 둘 다 맞아야 쓴다).
