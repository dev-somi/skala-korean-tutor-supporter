# TS-0006: 5~6급 문형 "과연 -을까", "-게끔 -어야 하다"가 1·2급 항목("-을까", "-게")으로 잡혔다
- 날짜: 2026-10-22
- 관련 모듈: `ai-server/app/curriculum/textbook_extract.py` (`match_standard`, `fragments`)
- 관련 ADR: [기술 ADR-0040](../adr/0040-unit-sheets-from-textbook-3a-6b.md) 결정 4

## 증상
3A~6B 본책에서 단원 시트를 뽑는데, 5A~6B 문형 일부가 엉뚱한 초급 항목으로 연결됐다.
```
ko5a 4과 '-게끔 -어야 하다'   → std-g-060 '-게' (2급)
ko5a 10과 '과연 -을까'        → std-g-035 '-을까' (1급)
ko5b 4과 '...은 ...이 -기로 유명하다' → std-g-005 (1급)
ko6b 8과 '..을 계기로 -게 되다' → 2급
```
또 5A~6B 과 절반은 문법이 0개였다 ("...은 -는다는 것이다", "...에 이르다").

## 원인
- `grammar_qa.match_forms`는 질문 글에서 문법을 찾는 함수라, **앞 낱말을 버리고 뒤를 잘라 가며** 표준 형태에 맞춘다. 3A~4B처럼 형태가 한 덩어리("-으려면")일 때는 맞지만, 5~6급 여러 조각 문형은 맞을 때까지 잘라서 첫 조각의 초급 항목이 걸린다.
- 처음에는 "결과 form이 후보와 글자가 같은지"로 거르려 했다. 그런데 `match_forms`가 돌려주는 form은 입력을 그대로 돌려줄 때가 있어("과연 -을까" → form "과연 -을까", keys `-ㄹ까`) 거르지 못했다. `form_keys`도 앞 낱말 "과연"을 버린다.
- 0개였던 과는 "..." 자리 표시와 앞 조사("...은") 때문에 통째로는 표준 목록에 없었다.

## 시도한 것
| 시도 | 결과 |
|---|---|
| 통째로 `match_forms` | 위 오매칭 |
| 결과 form == 후보일 때만 인정 | form이 입력 그대로라 거르지 못함 |
| `form_keys` 비교 | 앞 낱말을 버려서 같은 키가 나옴 |
| 여러 조각 문형(`...`, `낱말 -어미`)은 조각으로 나눠 맞추고, 가장 높은 등급 하나만, 3급 미만은 버림 | 오매칭 사라짐, 0개였던 과 일부("...은 -기 나름이다" 5급, "...에 따르면" 4급)가 잡힘 |

## 해결
`textbook_extract.py`: `COMPOUND`(`...`, `…`, "낱말 + 공백 + -")에 걸리는 형태는 `fragments()`로 나눠 조각마다 `match_forms`, 등급이 가장 높은 조각 하나만 쓰고 `MIN_FRAGMENT_LEVEL = 3` 미만이면 버린다. 한 덩어리 형태는 그대로 `match_forms`. 테스트 `test_compound_patterns_match_by_fragment_but_not_low_level_pieces`.

## 배운 점 / 다음에 주의할 것
- `match_forms`는 "질문 글 속 문법 찾기"용이라 관대하다. 교재 목차처럼 형태가 정해진 입력에 쓸 때는 결과가 입력과 정말 같은 항목인지 따로 확인해야 한다.
- 고급 교재에서 1·2급 항목이 학습 목표로 나오면 먼저 의심한다. 뽑은 항목의 등급을 교재 등급과 견주면 이런 오류가 바로 보인다.
