# ADR-0014: 수업 준비의 핵심은 "이 학생에게 맞춘 설명"이고, 개인화 축은 모국어·수준·관심사로 한정한다
- 상태: Superseded by ADR-0016, ADR-0017 (2026-10-20)
- 관련 모듈: `ai-server/app/agent/lesson_prep/` (briefing), `frontend` (수업안 검토 화면)
- 대체: [ADR-0016](0016-persona-anchor-textbook-standard-levels.md) (목적별 교재 선택, 표준 등급), [ADR-0017](0017-examples-from-materials-not-generated.md) (예문을 만들지 않고 찾기). 결과물 네 부분과 모국어 축은 ADR-0016이 이어 간다

## 배경 (Context)
수업 준비 시간이 드는 이유를 둘로 나눴다 ([ADR-0013](0013-sejong-public-materials.md)).
- **A. 내용 익히기**: 이 과의 목표, 수업 절차, 문법의 공식 설명. 학생이 누구든 같다. 교원용 지침서가 답을 갖고 있다.
- **B. 설명하기**: 이 문법을 이 학생에게 어떻게 설명할지. 모국어, 수준, 관심사, 약점에 따라 달라지고, 문화·맥락 설명도 들어간다.

PDF를 직접 읽는 것과 이 서비스를 쓰는 것의 차이는 B에서 나온다. 현장 튜터들의 글에서도 학생이 튜터를 바꾸는 이유로 "설명을 못 한다"와 "나를 기억하지 못한다"가 반복된다.

학생의 목표 유형(시험형, 콘텐츠형, 여행형, 목표 없음)에 따라 뼈대 교재부터 달라진다는 점도 확인했다. 하지만 마감까지 이틀이다.

## 결정 (Decision)
- 수업 준비 결과물은 네 부분으로 한다.
  1. **오늘 가르칠 것**: 학습 항목 + 볼 곳(책·쪽)
  2. **수업 진행 방법**: 지침서의 수업 절차 요약 (문제 A, 모든 학생 공통)
  3. **이 학생용 브리핑**: 공통 설명 + 모국어별 포인트 + 문화·맥락 + 수준 조정 + 관심사 예문 + 예상 질문 (문제 B)
  4. **수업 자료**: PPT (기존)
- 개인화 축은 세 가지로 한정한다.
  - **모국어** (일본어/영어): 모국어별 오류 포인트
  - **수준** (1급 안의 세부 수준, 자유 텍스트): 설명 언어 비율, 예문 어휘 범위
  - **관심사** (드라마, 여행 등): 예문 소재
- 학생의 목표 유형에 따라 뼈대 교재를 고르는 것은 이번에 하지 않는다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| 목표 유형별 교재 선택까지 | 시험형은 세종한국어, 여행형은 여행 한국어 등 | 학생 유형 네 가지에 모두 대응 | 교재마다 진도 데이터가 필요하고, 교재 간 학습 항목 ID 통합이 먼저다. 마감 안에 불가능 |
| 개인화 없이 지침서 요약만 | 문제 A만 해결 | 구현이 가장 쉽다 | PDF를 읽는 것과 차이가 없다 |
| 급수(TOPIK 1~6급) 칸 추가 | 수준을 정형 값으로 | 대시보드 정렬·필터 | 지금 자료가 1권(1급)뿐이라 모든 학생이 같은 값이다. 1급 안의 차이(한글을 읽는지 등)가 실제로 중요하다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 데모에서 "같은 문법, 다른 학생, 다른 설명"(유이 ja vs Emma en)을 보여 줄 수 있다.
- 대가: 중급 이상, 시험 준비, 교재 없는 회화 학생은 이번 범위 밖이다.
- 대가: 모국어별 포인트는 공식 자료에 없어서 검수된 지식이 따로 필요하다. 일본어권은 직접 검수할 수 있지만 영어권은 "미검수"로 표시해야 한다.

## 재검토 조건
- 2권 이후 자료를 진도 기준으로 쓰게 되면 → 급수 칸과 목표 유형을 추가한다
- 목표가 없는 학생이 대부분이라는 게 확인되면 → "단기 목표 제안" 기능을 앞으로 당긴다
