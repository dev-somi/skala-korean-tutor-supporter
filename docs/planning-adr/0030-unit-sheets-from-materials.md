# ADR-0030: 수업 준비의 "이번 과에 가르칠 것"을 자료에서 자동으로 만들고(초안), 진도는 표준 항목으로 센다
- 상태: Accepted (2026-10-21)
- 관련 모듈: 수업 준비, 학생 약점·진도, 수업 후 기록, 진척도 리포트
- 기술 설계: [docs/adr/0032](../adr/0032-unit-sheets-and-standard-ids.md)
- 관련 ADR: [ADR-0016](0016-persona-anchor-textbook-standard-levels.md) (결정 5의 범위를 넓힘), [ADR-0017](0017-examples-from-materials-not-generated.md), [ADR-0022](0022-structured-persona-uses-sejong-korean-1-6.md), [ADR-0028](0028-index-all-materials.md)

## 배경 (Context)
- 수업 준비는 손으로 정리한 「한국어 1」 2~4과 데이터에만 돌아간다. 다른 과를 고르면 실패한다.
- 받아 둔 자료는 전부 색인하고 있다 ([ADR-0028](0028-index-all-materials.md)). 지침서 1·2권은 과마다 "이번 과의 문법·어휘"가 같은 모양으로 적혀 있다.
- [ADR-0016](0016-persona-anchor-textbook-standard-levels.md): 순서는 중심 교재를 따르고(AI가 커리큘럼을 짜지 않는다), 표준 등급 목록을 공통 기준으로 둔다. 결정 5는 "다른 교재의 과별 데이터는 다음 단계"였다.
- 사용자 목표: 모든 자료를 바탕으로 학생에게 맞는 수업 자료를 뽑는다. 사용자 결정 (2026-10-21): 마감과 무관하게 전체를 진행 / 첫 교재는 「세종학당 한국어」 1~2 / 자동 초안 + 선생님 검수 표시.

## 결정 (Decision)
1. 과마다 **단원 시트**(이번 과의 문법·어휘·예문·대화·연습 + 출처 쪽)를 둔다. 손으로 만들지 않고 **색인된 자료에서 자동으로 만든다**. 순서와 내용은 교재가 정한 그대로다 (AI가 고르지 않는다).
2. 자동으로 만든 시트는 **"검수 전"**으로 표시한다. 수업 준비에 쓸 수 있지만 화면에 표시가 붙는다. 선생님이 확인하면 "검수됨"이 되고 다시 만들어도 덮어쓰지 않는다. 손으로 만든 2~4과는 "검수됨"으로 옮긴다.
3. **진도·약점·배운 항목은 국립국어원 표준 항목으로 센다.** 교재가 바뀌어도(1권 → 2권, 회화 교재) 기록이 이어진다. 표준 목록에 없는 표현("이름이 뭐예요?")은 수업 자료로 쓰되 진도에는 세지 않는다.
4. 예문은 자료에 실린 문장만 쓴다 ([ADR-0017](0017-examples-from-materials-not-generated.md)). 지침서에서는 학생에게 하는 존댓말 문장만 고른다 (교사용 지시문 제외).
5. 범위: 「세종학당 한국어」 1·2 (각 20과)부터. 다른 교재는 같은 방식으로 늘린다.

## 검토한 대안 (Alternatives)
| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 과별 데이터를 계속 손으로 만든다 | 정확하다 | 40과만 해도 오래 걸린다. "모든 자료"라는 목표와 멀다 |
| 표준 목록 등급 순서로 다음 항목을 고른다 (교재 없이) | 교재와 무관하다 | 같은 급 안의 순서가 목록에 없다. ADR-0016(교재 순서를 쓴다)과 어긋난다 |
| 자동 시트를 검수 없이 쓴다 | 빠르다 | OCR 오류가 진도에 그대로 들어간다 (사용자가 검수 표시를 골랐다) |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 「세종학당 한국어」 1·2의 40과 모두 수업 준비 재료가 생긴다. 손으로 만든 2~4과와 비교하면 문법은 모두 맞고, 뽑은 어휘에 틀린 것이 없다 (빠진 것은 있음).
- 대가: 지침서에 적힌 만큼만 나온다. 교실 사물처럼 지침서가 짧게 다룬 어휘는 빠진다 (본책 쪽에는 다음 과 어휘가 섞여 있어 보충에 쓰지 않는다).
- (2026-10-21) 대화·읽기·연습도 본책·익힘책에서 자동으로 채운다. 숙제는 익힘책 연습에서 고른다.
- 대가: 검수하는 화면은 아직 없다 (파일의 status를 바꾼다). 다음 단계에서 만든다.

## 재검토 조건
- 자동 시트의 오류를 선생님이 자주 고치면 → 검수 화면을 먼저 만들고, 검수 전 시트는 수업 준비에서 고를 수 없게 한다
- 다른 페르소나(회화·업무) 학생이 생기면 → 그 중심 교재의 시트를 만든다
