# ADR-0015: PPT는 만들지 않고, 고정된 7단계 수업 틀에 정확한 내용만 채워 내놓는다
- 상태: Superseded by [ADR-0032](0032-slide-plan-from-reference.md) (2026-10-21) — "PPT를 만들지 않는다"는 유지, 7단계 틀은 15장 슬라이드 구성안으로 바뀜
- 관련 모듈: `ai-server/app/agent/lesson_prep/` (graph, lesson_frame), `frontend` (수업안 검토 화면)
- 관련 ADR: [ADR-0001](0001-extend-existing-agent.md), [ADR-0014](0014-personalization-scope.md)

## 배경 (Context)
처음에는 기존 에이전트(수업 자료 PPT 생성)를 확장했다 ([ADR-0001](0001-extend-existing-agent.md)). 그런데 기획을 다시 보면서:
- 이 서비스의 가치는 "이 학생에게 무엇을 어떻게 가르칠지"라는 **내용**이다 ([ADR-0014](0014-personalization-scope.md)). PPT 모양을 만드는 데 드는 노력(슬라이드 분할, 글자 넘침 점검, PDF 변환)은 그 가치와 관계가 적다.
- 선생님마다 쓰는 자료 형식이 다르다 (자기 슬라이드, 화면 공유 문서, 교재 PDF). 서비스가 만든 PPT를 그대로 쓰기보다 내용을 가져다 자기 자료에 넣는 경우가 많다.
- 50분 1:1 온라인 수업은 학습자가 달라도 같은 흐름(이해 → 연습 → 활용 → 점검)을 쓸 수 있다. 틀이 고정되면 선생님은 내용만 준비하면 되고, 학생도 수업 리듬에 익숙해진다.

## 결정 (Decision)
- **PPT·PDF를 만들지 않는다.** 수업 준비는 선생님이 모든 범주를 승인하면 끝난다.
- 수업안은 **고정된 7단계 틀**로 내놓는다. 50분 기준 시간이며, 수업 길이에 비례해 조정한다.

| 단계 | 50분 기준 | 들어가는 내용 |
|---|---|---|
| 1. 워밍업 및 안부 | 5분 | 워밍업 질문 (학생 관심사·메모 기반) |
| 2. 복습 | 5분 | 복습 범주 (약점 + 직전 수업) |
| 3. 새 내용 도입 | 10분 | 새 어휘·새 문법 범주의 설명과 예문 |
| 4. 통제된 연습 | 10분 | 새 문법 범주 (교체·문장 완성) |
| 5. 의미 있는 활용 활동 | 12분 | 학생 목표·관심사에 맞춘 활동 1개 |
| 6. 오류 피드백 | 5분 | 수업 중 메모한 오류 (할 일만 안내) |
| 7. 마무리 및 과제 | 3분 | 숙제 범주 |

- 틀(순서·시간·단계별 할 일)은 코드에 고정하고, 학생마다 바뀌는 것은 **내용**뿐이다.
- 복습할 항목이 없으면 복습 시간을 통제된 연습에 준다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| PPT 유지 | 기존대로 승인 후 PPT 생성 | 바로 화면 공유할 자료가 생긴다 | 내용보다 모양에 시간이 든다. 선생님마다 자료 형식이 달라 그대로 쓰지 않는 경우가 많다 |
| 학습자 유형별로 틀을 다르게 | 초급/중급/시험 대비마다 다른 틀 | 더 맞춤형 | 지금 범위는 1권(초급)뿐이라 틀이 하나면 충분하다 |
| LLM이 수업 흐름을 매번 만들기 | 지침서 수업 개요를 요약하게 함 | 과마다 다른 흐름 | 로컬 모델에서 흐름이 매번 달라진다. 정답이 있는 일은 코드로 한다 (기술 ADR-0013) |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 수업 준비가 빨라지고(PPT 생성·렌더 점검·재시도가 없어짐), 결과물이 "무엇을 어떻게 가르칠지"에 집중된다.
- 대가: 선생님이 화면 공유 자료는 따로 준비해야 한다. 내용은 복사해서 쓸 수 있게 한다.
- PPT 생성 코드(`pptx_builder.py`, `render.py`)는 지우지 않고 그래프에서만 뗀다. 필요하면 "틀 → 슬라이드" 내보내기로 다시 붙일 수 있다.

## 재검토 조건
- 선생님들이 화면 공유 자료까지 만들어 달라고 자주 요청하면 → 7단계 틀을 그대로 슬라이드로 내보내는 기능을 붙인다
- 중급 이상·시험 대비 학생이 들어오면 → 수준·목적별 시간 배분표(2~3개 버전)를 둔다
- 초급 학생에게 "활용 활동 중 오류를 끊지 않는다"가 맞지 않으면 → 수준별로 즉시/지연 교정을 나눈다
