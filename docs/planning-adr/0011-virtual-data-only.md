# ADR-0011: MVP는 가상 데이터만 쓴다
- 상태: Accepted
- 관련 모듈: `data/students/`, `persistence/`

## 배경 (Context)
학생 실명, 수업 녹음 같은 정보를 다루면 동의, 보관 기간, 삭제 정책이 필요하다. 학생 정보는 LLM API로도 전송된다.

## 결정 (Decision)
**MVP는 가상 데이터만 쓴다.** 실제 학생 정보도 이름과 식별 가능한 정보를 바꾼 가명으로 입력한다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 가상·가명 데이터 | 샘플 데이터와 가명 | 개인정보 정책 없이 바로 개발 | (채택) |
| B. 실제 데이터 + 동의·보관 정책 | 정식 운영 | 실사용에 가까움 | 마감 안에 정책과 보안 구현 불가 |

## 결과 / 트레이드오프 (Consequences)
- 녹음 업로드(ADR-0003 P2)를 하려면 이 결정을 먼저 다시 봐야 한다.
- 저장소를 공개할 때 학생 데이터가 가상 데이터인지 확인한다.

## 재검토 조건
- 실제 학생 정보를 그대로 넣거나 녹음을 다루기 시작할 때
