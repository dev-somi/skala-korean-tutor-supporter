# ADR-0012: 프론트엔드 스택
- 상태: Proposed
- 관련 모듈: 프론트엔드

## 배경 (Context)
ADR-0008에 따라 대시보드, 검토 화면, 채팅(SSE 스트리밍)이 필요하다. 혼자서 4일 안에 백엔드와 함께 만들어야 한다. 실제로 쓸 서비스라는 목표도 있다.

## 결정 (Decision) — 제안
**React + Vite로 시작한다.** 2026-10-21(수) 오전까지 검토 화면이 동작하지 않으면 Streamlit으로 바꾼다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. React + Vite | 참고노트 레퍼런스 구조 (useChat + SSE) | 실사용에 맞는 UI, 채팅 스트리밍과 검토 화면을 자유롭게 구성 | (제안) |
| B. Streamlit | Python만으로 UI | 가장 빠름, 백엔드와 같은 언어 | 범주별 검토 같은 상태가 많은 화면과 SSE 스트리밍에 불편함. 실사용 UI로는 한계 |

## 결과 / 트레이드오프 (Consequences)
- React를 고르면 프론트(Zod)와 백엔드(Pydantic) 검증 규칙이 어긋나지 않게 해야 한다 (참고노트 6장).
- 전환 시점을 미리 정해 두어서 마감을 지킨다.

## 재검토 조건
- 2026-10-21 오전 진행 상황 확인 시
