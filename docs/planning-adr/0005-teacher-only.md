# ADR-0005: 선생님 전용 서비스로 만든다
- 상태: Accepted
- 관련 모듈: 전체 (인증·권한)

## 배경 (Context)
학생도 서비스에 들어와서 숙제를 내거나 단어를 복습하거나 리포트를 보게 할지 정해야 한다.

## 결정 (Decision)
**선생님만 사용한다. 학생은 서비스를 볼 수 없다.** 학생에게 줄 결과물(PPT/PDF, 피드백 메시지)은 선생님이 확인한 뒤 플랫폼 메시지 등으로 직접 보낸다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 선생님 전용 | 단일 사용자 도구 | 인증·권한·학생 UI가 필요 없음. AI 결과가 학생에게 바로 가지 않음 | (채택) |
| B. 학생 포털 포함 | 학생 로그인, 숙제 제출, 리포트 열람 | 학생과의 소통이 서비스 안에서 끝남 | 플랫폼 밖으로 학생을 데려와야 함. 범위가 두 배가 됨 |

## 결과 / 트레이드오프 (Consequences)
- 단일 선생님 기준이라 Teacher 엔티티와 로그인을 두지 않는다.
- 학생 피드백은 "복사해서 붙여넣기" 흐름이 된다.

## 재검토 조건
- 숙제 제출·채점을 서비스 안에서 하고 싶어질 때
- 다른 선생님도 쓰게 할 때 (다중 계정 필요)
