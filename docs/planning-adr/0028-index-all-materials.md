# ADR-0028: 받아 둔 세종학당 자료를 전부 색인한다 — 순위는 "무엇을 넣나"가 아니라 "무엇부터 돌리나"
- 상태: Accepted (2026-10-21)
- 관련 모듈: `ai-server/app/rag/catalog.json`, `ai-server/app/rag/batch.py`
- 기술 설계: [docs/adr/0031](../adr/0031-catalog-batch-and-embed-cache.md)
- 관련 ADR: [ADR-0025](0025-material-tiers.md) (이 ADR이 대체), [ADR-0013](0013-sejong-public-materials.md), [ADR-0017](0017-examples-from-materials-not-generated.md)

## 배경 (Context)
- [ADR-0025](0025-material-tiers.md)로 교사용 설명 24권만 색인했다. 문법 질문·브리핑 근거는 이걸로 동작한다.
- 사용자가 원하는 최종 모습: **받아 둔 모든 PDF가 색인되어 있고**, 그걸 바탕으로 학생에게 맞는 수업 자료를 뽑는다. 예문·대화는 본책, 연습은 익힘책, 업무 학생은 비즈니스 교재에서 가져와야 한다.
- 남은 PDF는 124권, 20,836쪽이다. OCR은 로컬이라 비용이 없고 시간만 든다 (쪽당 약 2초, 전부 약 12시간).
- 같은 책이 여러 판으로 들어 있다: 본책·익힘책·연습문제의 한국어·영어·일본어판, 「세종한국문화」 이미지판·글자 층판, 읽기·쓰기 합본과 분권.

## 결정 (Decision)
1. **전부 색인한다.** ADR-0025의 순위(1. 교사용 설명 → 2. 본책 → 3. 연습 → 제외)는 **돌리는 순서**로만 남긴다. 순서: 교원용 지침서 나머지 → 본책·비즈니스·문법 참고서·문화 2 → 익힘책·연습문제·어휘사전 → 근로자용·국제행사 → 영어·일본어판.
2. **같은 내용의 중복은 넣지 않는다**: 읽기·쓰기 분권 10개(합본과 같음), 「세종한국문화」 1권 다른 판 2개(이미 색인), 2권 이미지판(글자 층판을 씀).
3. **영어·일본어판은 글자만 뽑아 두고 색인은 나중에 한다.** 한국어 부분이 한국어판과 같아서, 지금 넣으면 같은 쪽이 검색 결과에 세 번 나온다. 핸드북처럼 언어판을 합치는 규칙을 만든 뒤에 넣는다 (모국어 설명은 그때 학생 언어별로 붙는다).
4. **근로자용·국제행사도 넣되 종류를 `special`로 따로 둔다.** 문법 질문은 지침서·핸드북만, 수업 준비는 정한 책만 찾으므로 섞이지 않는다. ADR-0025가 제외한 이유(검색 결과에 섞인다)는 종류 구분으로 해결한다.
5. 한 권씩 돌리고 기록한다. 끊겨도 이어서 한다 (사용자 요구, 기술 ADR-0031).

## 검토한 대안 (Alternatives)
| 대안 | 장점 | 기각 이유 |
|---|---|---|
| ADR-0025 순위대로 2순위(본책)만 추가 | 일이 적다 | 사용자의 목표는 "전부"다. 순위마다 다시 결정하면 계속 빈칸이 남는다 |
| 언어판까지 지금 전부 색인 | 한 번에 끝난다 | 같은 내용이 세 번씩 검색되어 다른 근거를 밀어낸다 |
| 근로자용·국제행사 계속 제외 | 검색이 깨끗하다 | 종류 구분으로 섞이지 않게 할 수 있다. "전부"라는 요구에 맞다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 예문·연습·비즈니스 자료가 생겨 다음 단계(수업 준비 기준을 표준 항목으로 옮기기)의 재료가 갖춰진다. 문법 질문과 원문 열기도 바로 넓어진다.
- 대가: 새 책은 형식을 맞추지 않은 "한 쪽 = 한 조각"이라 문법 태그가 `mentions`(본문 언급)만 붙는다. "이 쪽이 이 문법을 가르친다"(`teaches`)는 책 종류마다 규칙을 따로 만들어야 한다.
- 대가: OCR 품질이 표·그림이 많은 익힘책에서 낮을 수 있다.

## 재검토 조건
- 검색 결과에 연습 문제 쪽이 설명보다 자주 올라오면 → 종류별 가중치나 종류 필터를 둔다
- 언어판 합치기를 만들면 → 영어·일본어판을 색인에 넣는다 (`index: true`)
