# ADR-0025: 색인할 세종학당 자료를 3순위로 나눈다 — 교사용 설명 먼저, 본책 다음, 연습 자료는 나중
- 상태: Accepted (2026-10-21)
- 관련 모듈: `ai-server/app/rag/` (BOOKS 목록)
- 기술 설계: [docs/adr/0025](../adr/0025-form-key-tags-and-merged-editions.md)
- 관련 ADR: [ADR-0013](0013-sejong-public-materials.md), [ADR-0024](0024-grammar-qa-chat-p0.md)

## 배경 (Context)
- 세종학당재단 누리집에서 PDF 약 140개를 받았다 (`~/Desktop/한국어`). 교재, 교원용 지침서, 핸드북, 익힘책, 연습문제, 읽기·쓰기, 비즈니스, 근로자용, 어휘사전.
- 지도교수 의견: 전부 텍스트로 바꿔 두면 이후로는 계속 쓸 수 있다. 변환은 로컬이라 비용이 없다.
- 이 서비스의 핵심 가치는 "이 문법을 어떻게 가르치고, 학생 모국어로 어떻게 설명하나"다 (기획 ADR-0024). 교사용 설명이 가장 중요하다.
- 대상 학습자는 Preply 등에서 1:1로 배우는 일본어·영어권 학습자다 (기획 ADR-0007, 0016).

## 결정 (Decision)
| 순위 | 자료 | 이유 |
|---|---|---|
| **1. 교사용 설명** (지금) | 교원용 지침서·매뉴얼: 「세종학당 한국어」 입문, 1, 2, 3A·3B·4A·4B, 5A~6B / 「실용 한국어」 교원용 지침서 1~4 / 「세종한국문화」 교원용 지침서 1·2 / 「어휘와 문법」 핸드북 영어 1~4, 일본어 1·2 | "어떻게 가르치나"와 학생 모국어 설명이 직접 적혀 있다 |
| **2. 본책** (다음) | 「세종학당 한국어」 입문~4B 한국어판 전체 + 영어·일본어판(같은 쪽으로 합침) / 「세종한국문화」 1·2 | 예문 찾기(기획 ADR-0017), 교재 문법 상자의 모국어 설명 |
| **3. 나중** | 익힘책, 연습문제, 익힘책 교원용 지침서(회화 포함), 읽기·쓰기, 비즈니스 | 주로 연습 문제와 정답. 비즈니스는 업무 페르소나 학생이 생기면 |
| **따로** | 한국어 어휘사전 영어·일본어판 | 검색 자료보다 단어 → 번역 표로 쓰는 게 맞다 |
| **제외** | 농업·어업 근로자용, 국제행사, 고용허가제(EPS) 문법·어휘와 표현, 「세종한국문화」 이미지판(글자 층판과 중복) | 대상 학습자가 다르거나 중복 |

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| 전부 한 번에 | 140개 모두 색인 | 빈칸이 없다 | 근로자용·EPS 자료가 검색 결과에 섞인다. 책마다 형식 확인을 할 수 없다 |
| 데모에 필요한 것만 (지금 상태) | 지침서 1, 핸드북 3권, 문화 1 | 이미 동작한다 | 3급 이상 문법(-던 등)이 모두 "근거 없음"이다 |
| 본책 먼저 | 교재 본문부터 | 예문이 많다 | 이 서비스가 메우려는 빈칸은 예문보다 "설명 방법"이다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 입문부터 6급까지 교사용 설명이 생긴다. "아직 안 배운 문법"도 근거와 함께 보여 줄 수 있다.
- 대가: 3~4급은 지침서가 아니라 40쪽짜리 매뉴얼이라(형태 정보·정답·피드백 기준) 설명 방법이 1·2급보다 얇다.
- 대가: 「실용 한국어」(회화) 지침서와 「세종학당 한국어」 지침서가 같은 문법을 다르게 설명할 수 있다. 출처를 함께 보여 주고 선생님이 고른다.

## 재검토 조건
- 학생 질문에 연습 문제가 자주 필요하면 → 3순위 익힘책을 올린다
- 업무·여행 페르소나 학생이 생기면 → 해당 교재를 2순위로 올린다
