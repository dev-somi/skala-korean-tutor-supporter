# ADR-0004: 학생 등록은 정해진 엔티티 + 수동 입력 / 자연어 AI 채움 / 자유 메모
- 상태: Accepted
- 관련 모듈: `agent/student_intake/`, `/students`, `schemas/`

## 배경 (Context)
학생 초기 정보를 어떻게 받을지 정해야 한다. 정해진 칸이 있어야 수업 준비 에이전트가 안정적으로 쓸 수 있다. 하지만 체험수업 직후에는 칸을 하나씩 채우기보다 생각나는 대로 적는 게 편하다. 칸에 맞지 않는 정보(성격, 선호하는 수업 방식 등)도 있다.

## 결정 (Decision)
1. 학생 **데이터 엔티티를 먼저 정해 둔다** (PRD 7장 `Student`, `Weakness`).
2. 입력 방법은 세 가지를 모두 지원한다.
   - 폼에 **직접 입력**
   - **자연어로 설명** → AI가 엔티티 칸을 채운 초안 → 선생님 확인 후 저장 (ADR-0009)
   - 엔티티 칸과 별도로 무엇이든 적는 **자유 메모 칸**
3. 약점은 교재 항목 ID와 자유 서술을 둘 다 받는다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 수동 입력만 | 폼만 제공 | 구현이 가장 쉽고 정확함 | 입력이 귀찮아서 결국 안 쓰게 됨 |
| B. 자연어 → AI 채움만 | 폼 없이 대화로만 | 입력이 편함 | AI가 틀리면 고칠 방법이 필요하고, 정형 데이터를 보장하기 어려움 |
| C. 체험수업 메모 자동 추출 / 레벨 테스트 생성 | 별도 기능 | 등록 자동화 | MVP 범위를 넘음 |
| D. 엔티티 + 세 가지 입력 병행 | 위 A, B와 자유 메모 | 편하면서도 정형 데이터 유지 | (채택) |

## 결과 / 트레이드오프 (Consequences)
- AI 추출 결과는 코드가 다시 검사한다 (모국어 값이 `ja`/`en`인지, 약점 항목 ID가 실제 교재에 있는지).
- 자유 메모는 수업 준비·피드백 프롬프트에 그대로 넣어서 개인화에 쓴다.

## 재검토 조건
- 자유 메모에 자주 쓰는 내용이 반복되면, 그 내용을 정식 엔티티 칸으로 올린다.
