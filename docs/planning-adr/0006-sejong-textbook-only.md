# ADR-0006: 교재는 세종학당 한국어 1로 고정한다
- 상태: Superseded by ADR-0013 (2026-10-20)
- 관련 모듈: `data/textbook/`, `agent/lesson_prep/`

## 배경 (Context)
기존 에이전트는 「바로 배워 바로 쓰는 세종학당 한국어 1」 2~4과를 JSON으로 옮긴 데이터만 쓴다. 실제로는 다른 교재를 쓰는 선생님도 많고, 교재 없이 회화만 하는 학생도 많다.
후보는 (a) 세종학당 고정, (b) 선생님 교재·PDF 업로드, (c) 교재 없는 회화 학생도 지원이었다.

## 결정 (Decision)
**세종학당 한국어 1로 고정한다.** 자체 교재 기능은 지금 넣지 않고 확장 단계에서 다룬다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 세종학당 고정 | 기존 JSON 사용 | 데이터와 ID 체계가 이미 있음 | (채택) |
| B. 교재·PDF 업로드 | 업로드한 교재를 파싱해서 사용 | 여러 선생님에게 쓸모 있음 | PDF를 구조화하는 작업이 MVP보다 큼 |
| C. 교재 없는 회화 수업 | 주제 기반 수업 | 실제 수요가 많음 | 교재 항목 ID 기반 설계(복습, 약점 추적)와 맞지 않아 별도 설계가 필요 |

## 결과 / 트레이드오프 (Consequences)
- 목표 기반 로드맵(F2)을 하려면 1권 전체 목차 수준 데이터(`curriculum.json`)를 추가해야 한다.
- 교재는 저작권이 있으므로 저장소를 공개할 때는 `data/textbook/`을 뺀다.

## 재검토 조건
- 내 학생 중에 세종학당 1권 범위를 넘는 학생이나 회화만 원하는 학생이 생길 때
