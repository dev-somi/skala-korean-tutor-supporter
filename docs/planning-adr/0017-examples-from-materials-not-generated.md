# ADR-0017: 예문은 AI가 만들지 않고 세종학당 자료에서 찾아오며, 학생 등급을 넘는 예문은 거른다
- 상태: Accepted (2026-10-20)
- 관련 모듈: `ai-server/app/standard/levels.py`, `ai-server/app/rag/`, `ai-server/app/agent/lesson_prep/` (explain, briefing)
- 대체: [ADR-0014](0014-personalization-scope.md) (함께 [ADR-0016](0016-persona-anchor-textbook-standard-levels.md))
- 기술 설계: [docs/adr/0016](../adr/0016-standard-level-list-and-item-ids.md)

## 배경 (Context)
[ADR-0014](0014-personalization-scope.md)는 브리핑에 **관심사 예문**을 넣고, 수준에 따라 **예문 어휘 범위**를 조정하기로 했다. 둘 다 LLM이 예문을 만드는 방식이다. 그런데:
- LLM이 만든 한국어 예문에는 한국 사람이 실제로 쓰지 않는 말이 많다. 문법은 맞아도 어색하다. 선생님이 하나하나 고쳐야 해서 준비 시간이 줄지 않는다.
- 세종학당 공개 자료(교재, 교원용 지침서, 어휘와 문법 핸드북)에는 이미 검수된 예문이 많다. 핸드북은 문법마다 예문이 있다. 이 자료들은 이미 검색 색인으로 들어와 있다 ([ADR-0013](0013-sejong-public-materials.md)).
- 다만 여러 교재·단계에서 찾아오면 학생이 아직 모르는 단어가 섞인 예문도 걸린다.

## 결정 (Decision)
1. **예문의 출처는 세종학당 자료다.** 교재 JSON의 예문과 RAG로 찾은 공개 자료의 예문을 쓴다. 기본 흐름에서 LLM은 예문을 만들지 않는다.
2. **학생 등급으로 거른다.** 찾은 예문의 단어를 국립국어원 등급 목록([ADR-0016](0016-persona-anchor-textbook-standard-levels.md))과 맞춰, 학생 등급 안의 예문만 기본으로 보여 준다. 등급을 넘는 예문은 버리지 않고 "어려운 단어: 정책(4급)"처럼 이유를 붙여 접어 둔다. 판단은 선생님이 한다.
3. **관심사는 정렬 기준이다.** 드라마를 좋아하는 학생이면 찾은 예문 중 드라마와 관련된 것을 앞에 둔다. 관심사에 맞춰 새 예문을 만들지 않는다.
4. 맞는 예문을 못 찾으면 빈칸으로 두고 "자료에 맞는 예문 없음"이라고 보여 준다. 선생님이 직접 쓰거나, 선생님이 누를 때만 AI 예문을 만들고 `is_new: true`와 등급 판정 결과를 붙인다 (P1).
5. 이번 마감 범위: 예문 등급 판정·거르기 함수까지. 수업 준비 그래프의 설명 노드를 "찾아서 거르기"로 바꾸는 일은 다음 단계다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. LLM이 만들고 "AI 생성" 표시 (현행) | 관심사 맞춤 예문 | 학생마다 다른 예문 | 어색한 예문을 선생님이 고치느라 시간이 든다. 서비스의 근거(공식 자료) 원칙과 어긋난다 |
| B. LLM이 만들고 등급 목록으로 거르기 | 수준은 맞춤 | 어휘 수준은 보장 | 쉬운 단어로도 어색한 문장은 만들어진다. 어색함은 등급으로 거를 수 없다 |
| C. 교재 JSON 예문만 | 이번 과 교재 예문만 | 가장 정확하다 | 과마다 문법당 예문이 2~3개뿐이라 연습·복습에 모자란다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 모든 예문에 출처(책·쪽)가 붙는다. 학생 수준을 넘는 단어가 코드로 걸러진다.
- 대가: 관심사 맞춤이 약해진다. 자료에 드라마 예문이 없으면 드라마 예문도 없다.
- 대가: OCR 결과에서 예문 문장을 잘라내야 한다. OCR 오류가 예문에 그대로 들어올 수 있어 출처 쪽수를 함께 보여 준다.
- 대가: 예문 등급은 어휘만 본다. 문장 안 문법 표현의 등급은 아직 보지 않는다 (예: 1급 단어로 된 `-는 것 같다`(2급) 문장은 1급으로 판정된다).

## 재검토 조건
- 자료에서 맞는 예문을 못 찾는 경우가 잦으면 → 대안 B를 "선생님이 누를 때만"보다 넓게 연다
- 1급 학생에게 2급 문법 예문이 자주 섞인다는 게 확인되면 → 문장 안 문법 표현도 등급 목록과 맞춘다
