# ADR-0033: 15장 슬라이드마다 "수업에서 그대로 읽을 대본"을 함께 낸다 (한국어 발화 + 모국어 보조)
- 상태: Accepted (2026-10-21)
- 관련 모듈: `ai-server/app/agent/lesson_prep/` (write_slide_scripts), `frontend/src/components/SlidePlan.vue`
- 기술 설계: [docs/adr/0035](../adr/0035-slide-script-node.md)
- 관련 ADR: [ADR-0032](0032-slide-plan-from-reference.md) (15장 구성안, 이 결정이 확장), [ADR-0017](0017-examples-from-materials-not-generated.md)

## 배경 (Context)
- 15장 구성안(ADR-0032)의 교사 노트 [진행]·[기본 질문/예상 답변]은 요약이다. 선생님이 수업에서 무슨 말을 어떻게 꺼낼지는 다시 짜야 한다.
- 4범주(복습·어휘·문법·숙제) 대본은 있지만 범주 단위라서 슬라이드 장과 대응하지 않는다. 수업은 장 단위로 넘어간다.

## 결정 (Decision)
1. **장마다 대본을 낸다.** 15장 모두에 선생님이 순서대로 읽을 수 있는 대본이 붙는다: 선생님 발화, 학생이 할 법한 답(예상), 학생 답을 기다릴 지점, 다음 장으로 넘어가는 말, 학생이 어려워할 때 바꿔 말하는 줄.
2. **언어: 한국어 발화 + 보조 설명은 학생 모국어.** 학생에게 실제로 하는 말은 학생 수준에 맞는 짧은 한국어로 쓰고, 막힐 만한 줄에만 모국어 설명을 붙인다.
3. **새로 지어내지 않는다.** 예문은 초안·교재에서만, 교재 쪽수·음원은 입력에 있는 것만 쓰고 없으면 "확인 필요" (ADR-0017, 0032와 같은 원칙). 정답은 학생이 답한 뒤에 말한다.
4. 대본은 슬라이드 시간에 맞는 분량으로 쓴다(1분에 3줄 안팎). 시간에 비해 길면 경고만 한다.
5. 화면에서는 장을 펼치면 대본이 보이고, 15장 대본을 이어서 글로 복사할 수 있다. 장 하나만 다시 만들기와 선생님이 대본을 직접 고치는 기능은 이번 범위가 아니다.

## 검토한 대안 (Alternatives)
| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 교사 노트 [진행]을 더 길게 쓰기 | 칸이 늘지 않는다 | 요약과 대본이 한 칸에 섞여 읽기 어렵고, 수업 중에 그대로 읽을 수 없다 |
| 4범주 대본을 장에 나눠 보여 주기만 | LLM 호출이 늘지 않는다 | 범주 대본은 설명 위주라 질문→답→반응 순서가 없고, 담당 범주가 없는 장(1·3·11~14번)에는 대본이 없다 |
| 전부 학생 모국어 / 전부 한국어 | 단순하다 | 모국어만이면 학생에게 실제로 할 한국어 문장을 매번 다시 골라야 하고, 한국어만이면 입문 학생이 막힐 때 쓸 설명이 없다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 구성안을 펼쳐 놓고 그대로 읽으며 수업할 수 있다.
- 대가: 수업 준비에 LLM 호출이 15번 늘고(수정이 있으면 확정 때 15번 더), 시간이 더 걸린다.
- 대가: 대본의 한국어 자연스러움은 LLM 몫이고, 자동으로는 구조와 분량만 점검한다.

## 재검토 조건
- 선생님이 대본을 거의 그대로 쓰지 않고 다시 쓰면 → 장 단위 피드백·재생성, 직접 수정 기능
- 호출이 너무 느리면 → 단계별(어휘 2장 등)로 묶어 호출
