# ADR-0027: 출처 옆 "원문"을 누르면 선생님 컴퓨터의 원본 PDF가 그 쪽으로 열린다
- 상태: Accepted (2026-10-21)
- 관련 모듈: 브리핑 근거 자료, 문화 포인트 출처, 문법 질문 교재 근거
- 기술 설계: [docs/adr/0030](../adr/0030-local-pdf-open-via-ai-server.md)
- 관련 ADR: [ADR-0013](0013-sejong-public-materials.md), [ADR-0023](0023-culture-point-from-sejong-materials.md), [ADR-0024](0024-grammar-qa-chat-p0.md)

## 배경 (Context)
- 브리핑·문화 포인트·문법 질문에 세종학당 자료 출처(책·과·구역·쪽)가 붙는다. 화면도 "원문을 확인하세요"라고 안내한다.
- 그런데 원문을 보려면 선생님이 PDF 폴더에서 책을 찾아 열고 쪽을 직접 넘겨야 한다. 인쇄 쪽과 PDF 쪽이 달라서 더 헷갈린다.
- 선생님은 PDF를 이미 자기 컴퓨터에 받아 두었다 (`~/Desktop/한국어`, [ADR-0025](0025-material-tiers.md)). 서비스도 지금은 선생님 컴퓨터에서 돈다.
- 사용자 요구: 빨라야 한다.

## 결정 (Decision)
1. 출처 옆에 작은 **"원문"** 버튼을 둔다. 누르면 선생님 컴퓨터에 있는 원본 PDF가 **그 출처의 첫 쪽**으로 열린다 (브라우저 새 탭). 앞뒤 쪽은 PDF 안에서 넘겨 본다.
2. 적용 위치: 브리핑 "근거 자료", 수업 진행의 문화 포인트 출처, 문법 질문(채팅) 교재 근거.
3. PDF 위치는 폴더 하나를 한 번 스캔해 등록한다. 앞으로 새 책을 OCR하면 자동으로 등록된다.
4. 등록되지 않은 책은 버튼을 보이지 않는다. 열기에 실패하면 이유를 알림으로 보여 준다.

## 검토한 대안 (Alternatives)
| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 인용 쪽만 잘라 앱 안 팝업으로 | 서버가 원격이어도 된다 | 여는 데 시간이 걸리고 앞뒤를 못 본다. 사용자는 빠른 것을 원했다 |
| 원문을 열지 않고 인용문만 더 길게 | 만들 것이 없다 | OCR 글자라 표·그림이 깨진다. 원본 모양을 봐야 할 때가 있다 |
| 출처에 PDF 쪽 번호도 같이 적기 | 단순하다 | 여전히 폴더에서 책을 찾아야 한다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 근거 확인이 클릭 한 번이 된다. "출처를 붙인다"(PRD P1-A)가 "출처를 바로 확인한다"까지 간다.
- 대가: 서비스가 선생님 컴퓨터에서 돌 때만 된다. 지금 범위(개인 프로젝트, 로컬 데모)에서는 문제가 없다.

## 재검토 조건
- 서비스를 여러 선생님이 원격으로 쓰게 되면 → 앱 안에서 인용 쪽을 보여 주는 방식으로 바꾼다
