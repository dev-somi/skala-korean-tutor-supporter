# ADR-0019: 학습자별 진도·향상 리포트를 만든다 — 숫자는 코드가 계산하고, 학생에게는 개수와 늘어난 양만 보여 준다
- 상태: Accepted (2026-10-20)
- 관련 모듈: `ai-server/app/standard/report.py`, `backend/.../report/ReportController.java`, `frontend/src/pages/StudentReportPage.vue`
- 관련 ADR: [ADR-0016](0016-persona-anchor-textbook-standard-levels.md) (표준 등급 기준), [ADR-0018](0018-level-from-trial-test-persona-by-teacher.md) (현재·목표 수준), [ADR-0005](0005-teacher-only.md) (선생님 전용), [ADR-0009](0009-hitl-on-all-writes.md)
- 기술 설계: [docs/adr/0018](../adr/0018-progress-report-computed-in-ai-server.md)

## 배경 (Context)
실제 한국어 선생님들의 글(Threads, 2026년 9~10월, 약 20~30개)을 다시 정리했다.
- "준비 시간이 길다"는 고충은 있지만 "자료가 쌓이면 준다"는 반응이 많았다. 돈을 내고 해결할 문제로는 약해 보인다.
- 수업료가 내려가고 학생 모집이 어려워지면서 **학생이 떠나지 않게 하는 것(리텐션)이 곧 수입**이다.
- 선생님들은 학생마다 다른 진도와 **실력 향상 체크**를 중요하게 본다. 학생은 "나를 기억하는지", "늘고 있는지"로 선생님을 고른다.
- 서비스에는 이미 승인된 수업 기록(다룬 항목, 잘한 점, 오류), 약점의 생김·해결 날짜, 표준 등급 목록과 교재 대응표가 쌓여 있다. 이걸 학생에게 보여 줄 형태로 묶는 기능만 없다.

한계: 샘플이 작고 글 쓰는 사람에 치우쳐 있다. 리포트에 돈을 낼지는 아직 모른다.

## 결정 (Decision)
1. 학생마다 **진도·향상 리포트**를 만든다. 기간(최근 30일, 이번 달, 전체, 직접)을 고르면 다음을 보여 준다.
   - 수업 횟수·시간, 새로 배운 문법·단어, 누적
   - 표준 등급별로 배운 양 (1급 문법 45개 중 N개 등), 목표 등급까지 남은 문법
   - 잘한 점, 해결한 약점, 반복 오류(같은 항목 2번 이상, 상위 3개), 남은 약점
   - 학생에게 보낼 메시지 초안 (한국어 + 학생 언어)
2. **숫자와 문장은 코드가 만든다.** LLM은 쓰지 않는다. 리포트는 학생에게 가는 "성과 증명"이라, 없는 성과를 지어내면 신뢰를 잃는다. 문장은 언어별 템플릿이다.
3. **학생에게는 개수와 늘어난 양만 보여 준다.** 등급별 비율(735개 중 42개)은 선생님 화면에만 둔다. 초급 학생에게 작은 비율은 동기를 꺾는다.
4. **선생님이 확인하고 직접 보낸다.** 학생은 서비스에 접속하지 않는다 ([ADR-0005](0005-teacher-only.md)). 메시지는 화면에서 고친 뒤 복사해 플랫폼으로 보낸다. 리포트는 저장하지 않는다 (볼 때마다 기록에서 계산한다).
5. 반복 오류는 다음에 함께 연습할 것으로, 해결한 약점은 "극복한 것"으로 메시지에 넣는다. 약점을 "못하는 것"이 아니라 "다음 목표"로 보여 준다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. LLM이 리포트 문장 작성 | 기록을 주고 칭찬·요약을 쓰게 함 | 문장이 자연스럽고 학생 언어로 바로 나온다 | 숫자·성과를 틀리게 쓸 수 있다. 피드백 메시지처럼 Validator를 붙이면 느리고 비싸다. 템플릿으로 충분하다 |
| B. 학생용 리포트 페이지 (링크 공유) | 학생이 링크로 직접 봄 | 보기 좋다 | 학생 접속·개인정보·로그인 문제가 생긴다. 선생님 전용 원칙과 어긋난다 |
| C. 비율까지 학생에게 공개 | 표준 대비 % | 객관적이다 | 초급에서는 숫자가 너무 작아 역효과다. 목표 등급에 가까워지면 다시 볼 만하다 |
| D. 리포트를 저장·발송 이력 관리 | 월별 리포트 보관 | 변화 비교 | 이번 범위에서는 기록에서 다시 계산하면 된다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 이미 쌓인 데이터(수업 기록, 약점, 표준 등급)로 "학생의 성장"을 보여 준다. 서비스를 쓸수록 리포트가 풍부해진다 (쌓이는 맥락).
- 대가: 잘한 점·극복한 것은 선생님이 쓴 한국어 기록이라, 일본어·영어 메시지 안에서도 한국어로 나온다. 선생님이 고쳐서 보내야 한다.
- 대가: 표준 대응표가 「한국어 1」 2~4과뿐이라 등급별 숫자가 작다. 대응표가 늘수록 정확해진다.
- 대가: 승인된 기록만 센다. 기록을 미루면 리포트에 빠진다.

## 재검토 조건
- 선생님들이 학생 언어 문장을 매번 고친다면 → 잘한 점·극복한 것만 LLM으로 번역하고 한국어 원문을 함께 보여 준다
- 학생에게 보낸 리포트가 재등록·지속 수강과 관련 있다는 신호가 보이면 → 월별 자동 생성과 발송 이력을 둔다
- 목표 등급에 가까운 학생이 많아지면 → 학생용 메시지에 "목표까지 남은 양"을 넣는다
