# ADR-0018: 학생 수준은 체험수업 레벨테스트로 정한 표준 등급을 필수로 적고, 학습 목적은 선생님이 고른다 (AI는 추천만)
- 상태: Accepted (2026-10-20), 결정 5의 결과 처리(저장하지 않고 등록 화면으로 넘김)만 Superseded by [ADR-0021](0021-student-screen-level-test-saved-result.md) (2026-10-20)
- 관련 모듈: 학생 엔티티 (`backend` V2 마이그레이션, `frontend` 학생 폼), `ai-server/app/agent/intake.py`, 레벨테스트 (`ai-server/app/standard/level_test.py`, `frontend` 레벨테스트 화면)
- 관련 ADR: [ADR-0016](0016-persona-anchor-textbook-standard-levels.md) (페르소나·표준 등급), [ADR-0014](0014-personalization-scope.md) (급수 칸을 기각했던 결정), [ADR-0009](0009-hitl-on-all-writes.md)
- 기술 설계: [docs/adr/0017](../adr/0017-student-level-fields-and-level-test.md)

## 배경 (Context)
[ADR-0016](0016-persona-anchor-textbook-standard-levels.md)으로 진척도, 목표까지 남은 항목, 예문 거르기를 모두 표준 등급으로 재기로 했다. 그런데 학생 수준이 "초급 1" 같은 자유 텍스트라서 계산에 쓸 수 없다. 수준이 비어 있으면 그 기능들이 다 멈춘다.
- Preply 체험수업(25분)에서 선생님은 보통 레벨테스트를 한다. 수준을 정할 가장 믿을 만한 때와 근거가 이미 있다.
- [ADR-0014](0014-personalization-scope.md)는 급수 칸을 기각했다. 그때 이유는 "자료가 1권뿐이라 모든 학생이 같은 값"이었다. 이제는 등급 목록(1~6급)이 기준이라 전제가 바뀌었다.
- 체험수업에 오는 학생 중에는 한글을 아직 못 읽는 경우가 많다. 표준 교육과정은 1급부터라 이들을 1급과 구분할 칸이 필요하다.
- 학습 목적(페르소나)은 선택지가 4개뿐이고, 선생님이 체험수업에서 이미 물어본다.

## 결정 (Decision)
1. **현재 수준은 필수다.** "지금 배울 표준 등급"으로 적는다. 0 = 입문(한글부터), 1~6 = 표준 N급. 근거는 체험수업 레벨테스트이고, 날짜도 적는다. 자유 텍스트 수준 칸은 **세부 메모**로 남긴다 (한글을 읽는지, 받침 발음 등 1급 안의 차이).
2. 자연어 등록에서 AI는 **메모에 등급이 분명히 있을 때만** 현재 수준을 채운다 ("레벨테스트 2급", "한글 못 읽음" → 0). "초급"처럼 짐작이 필요하면 비워 두고, 선생님이 고르기 전에는 저장하지 못한다.
3. **학습 목적은 선생님이 고르는 칸**이다. 자연어 등록 때 AI가 추천값을 미리 골라 둘 뿐이다. 중심 교재는 학습 목적에서 코드가 정한다. 목표 수준(1~6)은 선택 칸이다.
4. 현재 수준과 학습 목적은 **언제든 바꿀 수 있다.** 수준은 선생님이 바꿀 때만 바뀐다. 나중에 진척도로 "올릴까요?"를 제안할 수는 있지만 결정은 선생님이 한다 ([ADR-0009](0009-hitl-on-all-writes.md)).
5. **체험수업 레벨테스트를 서비스에서 제공한다.** 국립국어원 등급 목록의 항목으로 문항을 만든다.
   - 한글 읽기 5개 → 1~6급마다 문법 질문 4~6개 + 어휘 6개. 문항마다 표준 항목 ID가 붙는다.
   - 선생님은 대화하면서 맞음/틀림만 누른다. 판정은 코드가 한다: 한 등급에서 확인한 문항의 70% 이상이면 통과, **처음으로 못 넘은 등급이 지금 배울 등급**이다.
   - 결과는 추천이다. [이 결과로 학생 등록]을 누르면 등록 화면에 등급·날짜·관찰 메모가 채워지고, 선생님이 확정한다.
   - 질문과 예시 답은 Claude가 쓴 초안이다. 선생님 검수 전이라고 화면에 표시한다. 각 등급 문항에는 그 등급보다 어려운 단어를 쓰지 않는다 (테스트로 확인).
6. [ADR-0016](0016-persona-anchor-textbook-standard-levels.md)에서 다음 단계로 미뤘던 학습 목적 칸을 이번에 넣는다. 다른 교재의 진도 데이터는 여전히 없어서, 어떤 목적을 골라도 진도는 「한국어 1」을 따른다. 화면에 그렇게 적는다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 수준은 자유 텍스트 그대로 | 현행 | 칸이 유연하다 | 진척도·예문 거르기를 계산할 수 없다 |
| B. AI가 메모를 보고 등급 추정 | 자연어 → 등급 | 선생님 입력이 준다 | "초급"이 1급인지 2급인지 근거 없이 정한다. 틀린 등급이 모든 계산을 틀리게 한다 |
| C. AI가 학습 목적을 정함 | 목표 문장 → 목적 확정 | 칸이 하나 준다 | 선택지 4개는 고르는 게 더 빠르다. 중심 교재를 정하는 무거운 결정이라 어차피 확인해야 한다 |
| D. 레벨테스트 없이 등급만 고르게 | 칸만 추가 | 구현이 작다 | 경력이 짧은 선생님은 "몇 급인지"를 정할 기준이 없다. 25분에 무엇을 물어볼지도 매번 고민한다 |
| E. 1급 안을 세분 (1급 하·상) | 등급을 더 잘게 | 초급 학생 구분이 섬세하다 | 표준 목록에 없는 구분이라 계산에 못 쓴다. 세부 메모로 충분하다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 모든 학생이 계산 가능한 수준을 갖는다. 레벨테스트 결과가 바로 학생 카드로 이어진다.
- 좋은 점: 체험수업에서 무엇을 물어볼지가 정해진다. 문항이 표준 항목에 묶여 있어 결과의 근거를 말할 수 있다.
- 대가: 이미 등록된 학생은 수준이 비어 있다 (지어내지 않는다). 학생 정보를 고칠 때 고르게 하고, 대시보드에 "수준 미정"으로 보여 준다.
- 대가: 레벨테스트 문항은 검수 전이다. 특히 5~6급 질문은 표현을 유도하기 어려워 "이해하고 자연스럽게 답하는가"에 가깝게 본다.
- 대가: 판정은 맞음/틀림 비율뿐이다. 발음·유창성은 관찰 메모로만 남는다.

## 재검토 조건
- 레벨테스트 추천과 선생님이 최종 고른 등급이 자주 다르면 → 통과 기준(70%)이나 문항을 고친다
- 진척도 데이터가 쌓이면 → "등급을 올릴까요?" 제안을 붙인다
- 플랫폼 레벨테스트 결과(예: 자체 진단)를 받을 수 있게 되면 → 그 값을 근거로 함께 적는다
