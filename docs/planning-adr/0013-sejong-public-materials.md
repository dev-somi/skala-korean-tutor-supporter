# ADR-0013: 교재 범위를 세종학당 공개 자료(교재·교원용 지침서·핸드북)로 넓힌다
- 상태: Accepted (2026-10-20) — "수업 구성의 기준 교재는 한국어 1" 항목만 Superseded by ADR-0016 (2026-10-20)
- 관련 모듈: `ai-server/data/textbook/`, `ai-server/data/rag/`, `ai-server/app/rag/`
- 대체: [ADR-0006](0006-sejong-textbook-only.md)

## 배경 (Context)
[ADR-0006](0006-sejong-textbook-only.md)은 「바로 배워 바로 쓰는 세종학당 한국어 1」 2~4과 JSON만 쓰기로 했다. 그 뒤 기획을 다시 보면서 알게 된 것:
- 선생님이 수업 준비에 오래 걸리는 이유는 두 가지다. **A. 내용 익히기**(이 과에서 무엇을 어떻게 가르치나)와 **B. 설명하기**(이 학생에게 어떻게 설명하나). A는 세종학당이 이미 공식 답을 갖고 있다.
- 세종학당재단은 교재뿐 아니라 **교원용 지침서**(과마다 학습 목표, 수업 개요표, 도입 → 배우기 → 써 보기 → 마무리 절차, 교사 발화 예시, 지도의 유의점)와 **어휘와 문법 핸드북**(문법마다 설명·예문, 언어별 판)을 무료로 공개한다.
- 지침서에는 과마다 「세종한국어 1A」, 「세종학당 실용 한국어 1」과의 주제·기능·문법·어휘 대응표가 있다. 교재끼리 잇는 매핑을 직접 만들 필요가 없다.
- 같은 문법이 교재마다 다른 과에 있다 (을/를: 한국어 1은 3과, 실용 한국어 1은 6과). 교재마다 순서와 말투도 다르다 (한국어 1은 `-습니다`를 먼저, 실용 한국어 1은 `-아요/어요`를 먼저 가르치고 1권에서 `-습니다`를 다루지 않음).

## 결정 (Decision)
- 서비스가 참고하는 자료를 **세종학당재단이 공개한 PDF 전체**로 넓힌다. 교재, 교원용 지침서, 어휘와 문법 핸드북이 대상이다.
- 이 자료들은 OCR해서 검색 색인으로 쓴다 (기술 설계는 [docs/adr/0014](../adr/0014-teaching-material-rag.md)).
- 수업 준비 결과에 **"어느 책 몇 쪽을 보라"는 출처**를 붙인다. 선생님이 원문을 바로 확인할 수 있게 한다.
- 수업 구성의 기준 교재(진도, 학습 항목 ID)는 지금처럼 「세종학당 한국어 1」로 둔다. 다른 교재는 참고 자료로만 쓴다.
- 이번 마감 구현 범위: 「세종학당 한국어 1 교원용 지침서」 전체와 「실용 한국어 1 어휘와 문법 핸드북(영어판)」을 색인한다. 수업 구성 JSON은 지금의 2~4과 그대로 둔다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 지금처럼 2~4과 JSON만 | ADR-0006 유지 | 추가 작업 없음 | 문제 A(내용 익히기)를 LLM이 지어낸 설명으로 대신하게 된다 |
| B. 모든 교재를 구조화 JSON으로 옮기기 | 과마다 어휘·문법·연습을 ID로 정리 | 코드가 전부 다룰 수 있다 | 292쪽 지침서 하나만 해도 수작업 검수가 크다. 마감 안에 불가능 |
| C. 선생님이 아무 PDF나 올리기 | 업로드 기능 | 어떤 교재든 지원 | 쪽 구조·메타데이터를 알 수 없어 출처와 학습 항목 연결이 약하다. 저작권 확인도 사용자마다 다르다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 브리핑과 수업 절차가 공식 자료를 근거로 나온다. 발표에서 "AI가 지어낸 설명이 아니라 지침서 몇 쪽 근거"라고 보여 줄 수 있다.
- 대가: 자료가 이미지 PDF라 OCR 품질에 기대야 한다. 표가 깨질 수 있다.
- 대가: 저작권. PDF, OCR 결과, 색인은 저장소에 넣지 않는다 (`.gitignore`의 `*.pdf`, `ai-server/data/rag/`). 각 자료의 이용 조건(공공누리 유형 등)은 공개 배포 전에 확인한다.

## 재검토 조건
- 세종학당 외 교재를 쓰는 선생님이 대상에 들어오면 → 대안 C(업로드)를 다시 본다
- 다른 교재를 진도의 기준으로 써야 하는 학생이 생기면 → 교재와 무관한 학습 항목 목록(문형 + 의미 단위 ID)을 만든다
