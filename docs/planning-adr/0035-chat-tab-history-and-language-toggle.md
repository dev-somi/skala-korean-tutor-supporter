# ADR-0035: 채팅을 전용 탭으로도 열고 대화 기록을 남긴다, 설명 언어는 토글로 고른다
- 상태: Accepted (2026-10-22)
- 관련 모듈: `frontend/src/pages/ChatPage.vue`, `frontend/src/components/ChatWidget.vue`, `backend/chat/`
- 관련 ADR: [기획 ADR-0008](0008-dashboard-plus-chat.md) (대시보드 + 채팅), [기획 ADR-0007](0007-explanation-languages.md) (설명 언어는 ja·en), [기획 ADR-0024](0024-grammar-qa-chat-p0.md) (교재 근거 문법 질문), 기술 [ADR-0041](../adr/0041-chat-history-in-postgres.md)·[ADR-0042](../adr/0042-nav-chat-tab-shared-conversation.md)

## 배경 (Context)
- 채팅은 오른쪽 아래 플로팅 창뿐이었다. 수업 중에 급하게 물을 때는 좋지만, 문법 근거 카드처럼 긴 답은 작은 창에서 보기 어렵다.
- 대화는 새로고침하면 사라졌다. 전에 물어본 "-아서 / -(으)니까" 답을 다시 보려면 또 물어야 했다.
- 일본어 학생과 영어 학생을 번갈아 가르친다. 학생을 지정하지 않고 물으면 문법 근거는 늘 일본어판이었고, 일반 질문 답에는 학생 언어 설명이 없었다.

## 결정 (Decision)
1. 주 메뉴에 **AI 채팅** 탭을 둔다. ChatGPT·Claude처럼 왼쪽에 대화 목록, 오른쪽에 큰 대화 화면.
2. 플로팅 창은 그대로 두고 **같은 대화를 공유**한다. 플로팅에서 묻던 대화를 탭에서 이어 가고, 플로팅의 [크게 보기]가 탭으로 연다.
3. **대화 기록을 남긴다.** 답에 보였던 것(글, 의도 태그, 문법 근거 카드, 화면 이동 버튼, 오류)을 그대로 다시 볼 수 있게 저장한다. 제목은 첫 질문 앞 30자, 이름 바꾸기·삭제 가능.
4. 입력창에 **설명 언어 토글**(자동 / 日本語 / English)을 둔다.
   - 자동: 학생이 지정되면 그 학생 모국어, 아니면 일본어 (지금까지와 같음)
   - 문법 질문: 고른 언어판 핸드북·모국어 노트를 근거로 보여 준다. 학생용 설명을 새로 만들지 않고 원문을 보여 준다는 기획 ADR-0024는 그대로다.
   - 일반 질문(표현·수업 방법): 답 끝에 학생에게 그대로 말해 줄 수 있는 그 언어 설명을 한두 문장 붙인다.
   - 조회·작업 요청에는 영향이 없다. 지원 언어는 기획 ADR-0007대로 ja·en뿐이다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 플로팅만 두고 [넓게 보기]로 키움 | 지금 방식 | 만들 것 없음 | 여전히 페이지 위에 떠 있어서 길게 읽기 불편하고, 기록이 없다 |
| B. 탭만 두고 플로팅 제거 | 채팅은 한 곳 | 단순함 | 수업 중 다른 화면(학생, 수업 준비)을 보면서 바로 묻기 어렵다 |
| C. 탭과 플로팅이 따로 대화 | 플로팅은 일회성 | 저장 범위가 작다 | 플로팅에서 한 좋은 답을 다시 못 찾는다 |
| D. 탭 + 플로팅, 같은 대화 | (채택) | 둘의 장점을 다 가진다 | — |
| 언어: 질문마다 "영어로" 쓰기 | 토글 없음 | 만들 것 없음 | 매번 써야 하고, 라우터가 언어 지시를 질문 내용으로 오해할 수 있다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 긴 답을 크게 보고, 지난 답을 다시 찾는다. 학생 언어를 바꿔 가며 바로 비교해 볼 수 있다.
- 대가: DB 표가 둘 늘고(기술 ADR-0041), 채팅 화면 코드를 위젯·탭이 나눠 쓰도록 쪼갰다.
- 일반 질문의 학생 언어 설명은 LLM이 쓴 것이라 교재 근거가 없다. 문법 비교는 문법 질문 경로가 원문을 보여 준다.

## 재검토 조건
- 대화가 많이 쌓여 목록에서 찾기 어려워지면 → 검색이나 학생별 묶음을 넣는다
- 선생님이 여러 명이 되면 → 대화에 선생님 구분을 넣는다
