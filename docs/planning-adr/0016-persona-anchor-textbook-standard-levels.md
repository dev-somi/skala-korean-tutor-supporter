# ADR-0016: 학생 페르소나가 중심 교재를 정하고, 국립국어원 표준 교육과정 등급 목록을 공통 기준으로 둔다
- 상태: Accepted (2026-10-20) — 중심 교재 표의 "체계적 학습 · TOPIK 준비" 줄만 Superseded by ADR-0022 (2026-10-20)
- 관련 모듈: `ai-server/data/standard/`, `ai-server/app/standard/`, 학생 엔티티 (`backend`, `frontend`)
- 대체: [ADR-0014](0014-personalization-scope.md) (함께 [ADR-0017](0017-examples-from-materials-not-generated.md)). [ADR-0013](0013-sejong-public-materials.md)의 "수업 구성의 기준 교재는 한국어 1" 항목도 이 ADR이 대체한다
- 기술 설계: [docs/adr/0016](../adr/0016-standard-level-list-and-item-ids.md)
- 이어지는 결정: [ADR-0018](0018-level-from-trial-test-persona-by-teacher.md) (학습 목적·현재 수준을 어떻게 정하나, 학습 목적 칸을 이번에 넣음)

## 배경 (Context)
처음 이 서비스로 풀려던 것을 다시 보니, 수업 준비에 필요했던 건 **틀**이었다. "N급이면 이런 어휘와 문법을 배운다"가 정리된 기준이 있어야 학생이 어디쯤 왔고 목표까지 무엇이 남았는지 말할 수 있다.

지금 기획은 「세종학당 한국어 1」의 과 순서를 모든 학생의 커리큘럼으로 쓴다. 학생마다 다른 건 설명 방식과 예문뿐이다. 그런데:
- 학생의 목적(시험, 일상 회화, 여행, 업무)에 따라 **배우는 순서와 범위부터** 다르다. 세종학당도 대상별로 교재를 따로 냈다. 「한국어 1」은 `-습니다`를 먼저, 「실용 한국어 1」은 `-아요/어요`를 먼저 가르친다.
- 약점 ID가 교재 ID(`u03-g02`)라서 교재가 바뀌면 기록이 끊긴다. 같은 을/를이 교재마다 다른 과에 있다.
- 국립국어원이 「국제 통용 한국어 표준 교육과정 적용 연구(4단계)」(2017)의 **어휘·문법 등급 목록**을 엑셀로 공개한다. 1~6급별 문법·표현 336개, 어휘 10,635개다. 이용 조건은 공공누리 제1유형(출처표시)이다.

## 결정 (Decision)
1. **학생마다 페르소나(학습 목적)를 정하고, 페르소나가 중심 교재를 정한다.** 진도와 배우는 순서는 그 교재를 따른다. AI나 선생님이 커리큘럼 순서를 새로 짜지 않는다. 교재 저자가 이미 검수한 순서를 쓴다.

| 페르소나 | 중심 교재 (세종학당재단) |
|---|---|
| 체계적 학습 · TOPIK 준비 | 세종한국어 1A~2B → [ADR-0022](0022-structured-persona-uses-sejong-korean-1-6.md)에서 「세종학당 한국어 1~6」으로 바꿈 |
| 일상 회화 | 세종학당 실용 한국어 1~2 |
| 여행 | 여행 한국어 |
| 업무 | 비즈니스 한국어 1~2 |
| (지금 데이터가 있는 교재) | 바로 배워 바로 쓰는 세종학당 한국어 1 |

   전용 교재가 없는 목적(드라마·콘텐츠)은 일상 회화 교재 + 관심사로 처리한다.
2. **국립국어원 등급 목록을 모든 교재에 공통인 기준으로 둔다.** 교재 항목마다 표준 항목(등급)을 잇는다. 이 기준으로:
   - 학생 수준과 진척도 ("1급 문법 45개 중 30개 배움")
   - 목표 등급까지 남은 항목
   - 교재가 바뀌어도 이어지는 약점 기록
   - 예문이 학생 수준에 맞는지 판정 ([ADR-0017](0017-examples-from-materials-not-generated.md))
3. 화면에는 "표준 N급"으로 쓴다. TOPIK 급수와 같은 6단계라 거의 맞물리지만 공식적으로 같은 기준은 아니라서 "TOPIK N급"이라고 쓰지 않는다.
4. [ADR-0014](0014-personalization-scope.md)에서 그대로 가져가는 것: 수업 준비 결과물 네 부분(오늘 가르칠 것, 수업 진행 방법, 이 학생용 브리핑, 수업 자료), 모국어 축. 수준 축은 자유 텍스트에서 표준 등급으로 바뀐다. 관심사 축은 예문을 만드는 데 쓰지 않고 찾은 예문의 순서를 정하는 데 쓴다 ([ADR-0017](0017-examples-from-materials-not-generated.md)).
5. **이번 마감(2026-10-22) 범위**: 등급 목록 데이터, 「한국어 1」 2~4과 문법 → 표준 항목 대응표, 예문 어휘 등급 판정. 학생 페르소나 칸과 다른 교재의 과별 데이터는 다음 단계다. 지금 데이터가 있는 교재가 하나라서 페르소나 칸을 넣어도 모든 학생이 같은 교재로 간다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 교재 하나 고정 (현행) | 모든 학생이 「한국어 1」 순서 | 추가 데이터 없음 | 목적이 다른 학생에게 순서·범위가 안 맞는다. 약점 기록이 교재에 묶인다 |
| B. 목적별 트랙 순서를 직접 짜기 | 등급 목록에서 항목을 골라 트랙마다 순서를 정함 (AI 초안 + 선생님 검수) | 교재 없는 목적도 대응 | 교재 저자가 이미 한 일을 다시 한다. AI가 짠 순서의 교육적 타당성을 선생님이 모두 검수해야 한다 |
| C. 교재만 바꾸고 등급 목록 없이 | 페르소나 → 교재만 | 단순하다 | 교재끼리 수준을 비교할 수 없고, 목표 등급까지의 거리와 예문 수준을 판단할 기준이 없다 |
| D. 한국어 학습용 어휘 목록 (2003) | 국립국어원 5,965개, A/B/C 3단계 | 오래 쓰인 목록 | 3단계라 6급 체계와 안 맞고 문법이 없다. 4단계 목록이 상위 호환이다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 커리큘럼 순서를 검수할 부담이 없다. 등급 목록은 공공누리 제1유형이라 저장소에 넣을 수 있다 (세종학당 교재 PDF와 다르다).
- 좋은 점: "AI가 정한 순서"가 아니라 "세종학당 교재 순서 + 국립국어원 등급"이라고 근거를 댈 수 있다.
- 대가: 교재마다 과별 문법·어휘 목록 데이터가 필요하다. 지금은 「한국어 1」 2~4과만 있다. 새 교재는 OCR 파이프라인([기술 ADR-0014](../adr/0014-teaching-material-rag.md))에 넣고 과별 목록을 뽑아야 한다.
- 대가: 교재 항목 → 표준 항목 대응표를 선생님이 검수해야 한다. 대표형 글자로 맞추는 일이라 양은 적다 (「한국어 1」 2~4과 문법 7개).
- 대가: 표준 목록에 문법으로 없는 교재 항목이 있다 (`이/가 아니다` → 어휘 `아니다`로 잇는다).

## 재검토 조건
- 전용 교재가 없는 목적의 학생이 많아지면 → 등급 목록에서 고른 트랙(대안 B)을 그 목적에만 둔다
- 국립국어원이 표준 교육과정을 개정하면 → 등급 목록을 다시 가져온다 (`uv run python -m app.standard.importer`)
- 선생님 자체 교재를 쓰는 학생이 생기면 → 그 교재 항목도 같은 대응표로 표준 항목에 잇는다
