# ADR-0034: 대시보드는 월간 수업 달력 — 날짜를 누르면 그날 수업의 준비 상태를 본다
- 상태: Accepted (2026-10-22)
- 관련 모듈: `frontend/src/pages/DashboardPage.vue`, `GET /api/lessons?from&to`
- 기술 설계: [docs/adr/0039](../adr/0039-lessons-range-endpoint.md)
- 관련 ADR: [ADR-0008](0008-dashboard-plus-chat.md) (대시보드 + 채팅. 이 ADR은 그중 대시보드 구성만 바꾼다), [ADR-0010](0010-success-metric-prep-time.md) (시간 비교 위치가 대시보드 → 지표 탭으로)

## 배경 (Context)
- 대시보드에 할 일 4칸(미처리 기록, 승인 대기 수업안, 기록을 쓸 수업, 확인할 레벨테스트), 학생 카드, 시간 측정이 같이 있었다.
- 직접 써 보니 한눈에 들어오는 게 없다. 선생님이 대시보드를 열 때 알고 싶은 건 "다음 수업이 언제고, 그 수업 준비가 끝났나"이다.
- 학생 카드는 [학생] 탭에, 시간 측정은 [더보기 › 지표]에 이미 같은 내용이 있다.

## 결정 (Decision)
1. 대시보드는 **월간 달력** 하나로 한다. 칸마다 그날 수업을 학생 이름 + 상태 색 점으로 보여 준다.
2. 날짜를 누르면 오른쪽(좁은 화면은 아래)에 그날 수업마다 준비 체크(준비 시작 · 수업안 확정 · 지난 수업은 기록 승인)와 지금 할 버튼 하나를 보여 준다.
3. 상태는 6가지: 준비 전 / 준비 중 / 준비 완료 / 기록 필요(날짜가 지났는데 기록 없음) / 기록 확인 대기(AI 초안 승인 전) / 끝.
4. 할 일·학생 카드·시간 측정은 대시보드에서 뺀다. 지난 수업의 기록 여부는 달력 색으로 대신 보인다. 레벨테스트 확인 대기는 레벨테스트 메뉴에서만 본다.
5. 날짜를 안 정한 수업은 달력 아래 "날짜 미정"에 모은다. 위 바의 [수업 잡기]로 수업을 만든다(기존 수업 준비 창).

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 지금 구성 유지 | 할 일 + 학생 + 시간 | 이미 있음 | 한눈에 안 들어온다 |
| B. 주간 달력 | 이번 주 7칸에 수업 카드를 펼침 | 상태가 바로 보인다 | 다음 주 이후 수업은 넘겨야 보인다 |
| C. 월간 + 아래 "다가오는 수업" 목록 | 달력과 목록을 같이 | 가까운 수업이 순서대로 보인다 | [수업 준비] 탭과 겹친다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 열자마자 이번 달 수업과 준비가 안 된 수업(빨강·주황)이 보인다.
- 대가: 레벨테스트 확인 대기 알림이 대시보드에서 사라진다. 시간 비교는 지표 탭에서만 본다.

## 재검토 조건
- 레벨테스트 결과를 반영하지 않고 놓치는 일이 생기면 → 대시보드에 작은 알림 줄을 다시 둔다
- 하루 수업이 많아져(4개 이상) 칸이 모자라면 → 주간 보기를 추가한다
