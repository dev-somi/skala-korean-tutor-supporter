# ADR-0001: 기존 수업 자료 생성 에이전트를 확장한다
- 상태: Accepted
- 관련 모듈: `agent/lesson_prep/` (기존 `korean-ppt-ai-agent/src/`)

## 배경 (Context)
`korean-ppt-ai-agent`는 교재 JSON과 학생 프로필을 받아 4개 범주의 수업안, 개인화 설명, 대본, PPT를 만든다. 자동 검토 루프, 선생님 검토(HITL), SQLite checkpointer, 가짜 LLM 테스트까지 갖춰져 있다.
새 서비스는 이 기능을 "학생 학습 관리"로 넓히는 것이다. 마감까지 4일뿐이다.

## 결정 (Decision)
기존 에이전트를 새 서비스의 **"수업 준비" 모듈로 흡수**하고 그 위에 학생 관리, 수업 후 기록, 대시보드, 채팅을 붙인다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| A. 기존 에이전트 흡수·확장 | 그래프와 스키마를 그대로 옮기고 노드를 추가 | 이미 검증된 흐름과 테스트를 재사용, 4일 안에 가능 | (채택) |
| B. 새로 만들고 일부만 재사용 | 새 구조로 처음부터 설계 | 구조를 깔끔하게 다시 짤 수 있음 | 마감 안에 수업 준비 기능을 다시 만들 시간이 없음 |

## 결과 / 트레이드오프 (Consequences)
- 기존 `StudentProfile`, `LessonRecord` 스키마를 확장해야 한다 (약점 자유 서술, 관심사, 자유 메모 등).
- CLI용 `interrupt` 기반 HITL을 API·GUI로 옮기는 작업이 필요하다.
- 기존 설계 원칙("교재 원문은 바꾸지 않고 ID로만 참조")을 새 기능에도 그대로 적용한다.

## 재검토 조건
- 자체 교재 업로드처럼 교재 구조가 크게 달라지는 기능을 넣을 때, 기존 스키마가 걸림돌이 되면 다시 본다.
