# ADR-0023: 매 수업에 문화 포인트를 넣는다 — 진도는 교재, 문화는 세종학당 자료에서 RAG로 골라 정리
- 상태: Accepted (2026-10-20)
- 관련 모듈: `ai-server/app/agent/lesson_prep/` (briefing, lesson_frame), `ai-server/app/rag/`, `frontend` (LessonFrame)
- 기술 설계: [docs/adr/0023](../adr/0023-culture-candidates-rag-and-teacher-pick.md)
- 관련 ADR: [ADR-0013](0013-sejong-public-materials.md), [ADR-0015](0015-no-ppt-fixed-lesson-frame.md), [ADR-0017](0017-examples-from-materials-not-generated.md)

## 배경 (Context)
한국어 수업에는 한국 문화가 꼭 들어가야 한다. 그런데:
- 「바로 배워 바로 쓰는 세종학당 한국어 1」 교원용 지침서에는 문화 내용이 과마다 고르지 않다. 1과(인사법), 2과(가족 호칭과 나이)처럼 참고 상자가 있는 과도 있고, 4과처럼 거의 없는 과도 있다.
- 세종학당재단의 「세종한국문화 1」(145쪽, 한국어·영어 병기)은 8과 32개 주제(교통, 공연 문화, 효 문화, 성씨와 이름, 한복, 발효 식품 등)를 다룬다. 다만 「한국어 1」의 과와 짝지어져 있지 않다.
- 선생님은 "책을 따라 가르치면서 문화를 덧붙여 알려 주고 싶은데, 그때마다 검색하기는 애매하다". 웹 검색 결과는 출처와 정확성을 믿기 어렵다.
- 문화는 학생 나라마다 다르게 받아들인다. 비교하면 수업이 살아나지만, 로컬 모델이 학생 나라에 대해 단정하면 틀리거나 고정관념이 섞인다.

## 결정 (Decision)
1. **매 수업 "문화 포인트"가 하나 들어간다.** 따로 단계를 만들지 않고 새 문법·대화문을 배우는 **"새 내용 도입" 단계**에 붙인다. 7단계 틀과 시간은 그대로다.
2. **한국 쪽 문화 내용은 세종학당 자료에서만 가져온다.** 이번 과의 주제(과 제목·대화문·어휘)로 「세종한국문화 1」과 지침서를 검색해 후보를 찾고, 출처(책·쪽)와 원문을 붙인다. 요약은 원문 안의 내용만 쓴다.
3. **학생 나라와의 비교는 "질문"으로 만든다.** "일본에서도 ~해요?"처럼 학생에게 묻는다. 학생 나라에 대해 서비스가 단정하지 않는다. 학생이 자기 나라를 가장 잘 알고, 대답이 그대로 말하기 활동이 된다.
4. **선생님이 후보 중에서 고른다.** 1순위가 기본이고, 다른 후보로 바꿀 수 있다. 검색만으로 고르면 가끔 엇나가기 때문이다.
5. 자료에서 맞는 문화를 못 찾으면 지어내지 않고 "선생님이 채워 주세요"로 표시한다 ([ADR-0017](0017-examples-from-materials-not-generated.md)과 같은 원칙).

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| 문화 단계를 따로 (3~5분) | 7단계에 "문화" 단계 추가 | 수업안에서 잘 보인다 | 문화는 그 문법·대화문을 배울 때 같이 배워야 한다. 말하기 시간이 준다 |
| 과별 문화 주제를 손으로 정해 두기 | 「한국어 1」 과 ↔ 「세종한국문화」 주제 표 | 가장 정확하다 | 과가 늘 때마다 표를 만들어야 한다. 학생 관심사에 따라 바꿀 여지가 없다 |
| LLM이 문화 설명을 직접 쓰기 | 과 주제만 주고 생성 | 자료가 없어도 된다 | 로컬 모델이 사실을 틀린다 (모국어 칸에서 확인). 출처가 없다 |
| 학생 나라 문화를 LLM이 설명 | "일본에서는 ~한다" | 비교가 분명하다 | 틀리거나 고정관념이 섞일 위험. 1:1 수업에서 학생이 바로 알아챈다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 선생님이 따로 찾지 않아도 출처가 있는 문화 내용과 비교 질문이 매 수업에 붙는다. 2026-10-20 로컬 qwen3:8b로 확인한 예: 2과(가족) → 돌림자·효도와 어버이날, 3과(드라마) → 공연에서 팬들이 따라 부르는 문화.
- 좋은 점: 비교 질문이 학생 이야기를 끌어내서 기획 ADR-0019·0020의 "학생이 떠나지 않는 맞춤 수업"과 이어진다.
- 대가: 「세종한국문화」의 한국어 문장은 1급보다 어렵다. 1급 학생에게는 선생님이 소개하는 소재로 쓴다 (영어권은 병기된 영어를 보여 줄 수 있다).
- 대가: 호칭·존댓말 같은 언어 문화는 지침서 참고 상자에만 있어 잘 걸리지 않는다. 지금은 생활·전통 문화가 주로 나온다.
- 대가: 선생님이 고른 후보는 저장하지 않는다 (화면과 복사 글에만 반영).

## 재검토 조건
- 엉뚱한 후보가 자주 1순위로 나오면 → 과별 문화 주제 표(대안 2)를 일부 과에만 둔다
- 언어 문화(호칭, 존댓말, 인사)가 꼭 필요하다는 피드백이 많으면 → 지침서 참고 상자를 따로 뽑아 표준 문법 항목에 연결한다
- 「세종한국문화 2」나 다른 문화 자료가 들어오면 → 색인에 추가만 한다
