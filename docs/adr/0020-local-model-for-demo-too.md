# ADR-0020: 데모·평가도 로컬 qwen3:8b로 한다 — 품질은 모델이 아니라 절차와 데이터로 맞춘다
- 상태: Accepted (2026-10-20)
- 관련 모듈: `.env`, `ai-server/app/agent/lesson_prep/` (auto_review, briefing), `ai-server/data/standard/`
- 대체: [ADR-0012](0012-local-ollama-for-dev.md)의 "데모·평가 수치는 Anthropic으로" 항목
- 관련 ADR: [ADR-0013](0013-process-over-model.md), [ADR-0021](0021-auto-review-llm-advisory.md), [ADR-0022](0022-l1-notes-data.md)

## 배경 (Context)
[ADR-0012](0012-local-ollama-for-dev.md)는 개발 중에만 로컬 모델을 쓰고, 데모 녹화와 평가는 Anthropic으로 하기로 했다.
2026-10-20에 화면과 같은 경로(Spring → ai-server)로 유이(ja)·Emma(en)의 3과 50분 수업을 qwen3:8b로 준비해 보니:
- 전체 흐름(준비 → 검토 → 승인 → 저장)은 동작한다. 지침서 근거 문법 포인트, 워밍업 질문, 활용 활동은 쓸 만했다.
- LLM 자동 검토가 같은 수업안에 4번 연속 "실패"를 내서 재시도 한도까지 돌았다. 유이 수업 준비가 10분을 넘겼다. 코드 검사(ID·복습·시간 합계)는 매번 통과했다.
- 근거 자료가 없는 칸(모국어 화자가 자주 틀리는 점, 예상 질문)은 틀린 문법 설명이 섞였다.

Anthropic으로 바꾸면 나아지겠지만 개발 내내 토큰 비용이 부담이었고, 데모·평가까지 API를 쓰는 건 받아들이기 어렵다.

## 결정 (Decision)
- **데모와 평가도 로컬 `qwen3:8b`로 한다.** Anthropic은 코드 경로만 남긴다 (`.env`만 바꾸면 쓸 수 있다).
- 로컬 모델에서 드러난 문제는 모델을 바꾸지 않고 [ADR-0013](0013-process-over-model.md)의 원칙(정답은 코드, 지식은 데이터, LLM은 작은 칸)을 더 밀어붙여 푼다.
  - 흔들리는 LLM 판정이 재시도를 일으키지 않게 한다 → [ADR-0021](0021-auto-review-llm-advisory.md)
  - 모국어별 포인트는 검수된 데이터에서 꺼낸다 → [ADR-0022](0022-l1-notes-data.md)
- 발표의 Before/After는 "같은 로컬 모델, 절차·데이터 적용 전후"로 비교한다.

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| ADR-0012 유지 (데모만 Anthropic) | 데모 직전에 키 교체 | 품질이 가장 좋다 | 비용 부담. 또 데모 품질이 "실제로 쓸 환경"과 달라진다 |
| 로컬 모델 키우기 (qwen3:14b 등) | 더 큰 로컬 모델 | 비용 없음 | 16GB 맥북에서 느리고 메모리가 모자라다 (ADR-0012 재검토 조건) |
| 프롬프트만 계속 다듬기 | 모델·구조 그대로 | 변경이 작다 | 지식 부족은 프롬프트로 해결되지 않는다 (2026-10-20 예시 프롬프트를 넣자 예시 내용을 그대로 베꼈다) |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: API 비용 0. 데모가 실제 사용 환경과 같다. "작은 모델로도 되는 설계"가 발표의 중심 주장이 된다.
- 대가: 긴 생성(설명·대본)의 품질과 속도는 여전히 로컬 모델 수준이다. 설명을 자료 근거로 바꾸는 일([기획 ADR-0017](../planning-adr/0017-examples-from-materials-not-generated.md)의 다음 단계)이 남는다.
- 대가: 평가 수치(수업 후 기록 추출 정확도)도 로컬 모델 기준으로 다시 잰다. 이전 Sonnet 수치(0.969)와 바로 비교하지 않는다.

## 재검토 조건
- 로컬 모델로 수업 준비가 데모에 쓸 수 없을 만큼 느리면 → 설명·대본 생성을 줄이거나 자료 근거로 바꾼다
- 메모리가 더 큰 머신을 쓰게 되면 → 더 큰 로컬 모델로 같은 평가셋을 돌려 비교한다
