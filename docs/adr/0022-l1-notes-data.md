# ADR-0022: 모국어별 지식은 표준 ID 기준 데이터 파일 — Claude 초안 + 선생님 검수, LLM은 없는 문법만
- 상태: Accepted (2026-10-20)
- 관련 모듈: `ai-server/data/standard/l1_notes.json`, `ai-server/app/standard/l1_notes.py`, `ai-server/app/agent/lesson_prep/nodes.py` (`briefing`), `frontend` (BriefingPanel)
- 관련 ADR: [ADR-0013](0013-process-over-model.md), [ADR-0016](0016-standard-level-list-and-item-ids.md), [ADR-0020](0020-local-model-for-demo-too.md), [기획 ADR-0017](../planning-adr/0017-examples-from-materials-not-generated.md), [기획 ADR-0018](../planning-adr/0018-level-from-trial-test-persona-by-teacher.md)

## 배경 (Context)
브리핑의 "모국어 화자가 자주 틀리는 점"과 "예상 질문"은 공식 자료(교원용 지침서, 핸드북)에 없다. 지침서 설명은 학습자 모국어와 상관없이 공통이다. 그래서 LLM 지식에서 만들었다.

2026-10-20 로컬 qwen3:8b로 돌려 보니 이 칸에 틀린 문법 설명이 섞였다 ("'도'는 문장 끝에 붙일 수 없다", 예문이 설명과 맞지 않는 답 등). 데모·평가도 로컬 모델로 하기로 했으므로([ADR-0020](0020-local-model-for-demo-too.md)) 모델을 바꿔 해결할 수 없다.

이 지식은 학생이 아니라 **문법 × 모국어**에 달려 있다. 한 번 정확히 써 두면 같은 문법을 배우는 같은 모국어 학생 모두에게 쓸 수 있다.

## 결정 (Decision)
1. **데이터 파일** `data/standard/l1_notes.json`에 문법(구문)마다 `ja`, `en` 노트를 둔다. 노트 = 자주 틀리는 점 2~3개, 예상 질문과 답 2개, 설명 팁 1개, `reviewed`.
2. **키는 국립국어원 표준 항목 ID**다 ([ADR-0016](0016-standard-level-list-and-item-ids.md)). 교재 항목 → `textbook_map` → 표준 ID로 찾는다. 교재가 바뀌어도 같은 노트를 쓴다. 표준 목록에 문법으로 없는 구문(`이/가 아니다`)은 어휘 ID(`아니다`)로 잇고, 이런 구문 노트가 맞으면 일반 노트(`이/가`)보다 먼저 쓴다.
3. **작성은 Claude 초안, 확정은 선생님 검수**다. 레벨테스트 문항([기획 ADR-0018](../planning-adr/0018-level-from-trial-test-persona-by-teacher.md))과 같은 방식이다. 처음 버전은 모두 `reviewed: false`다. 노트에는 교재 원문을 넣지 않아서 저장소에 둘 수 있다.
4. **브리핑**: 수업 문법의 노트를 코드가 꺼내 넣는다. 노트가 없는 문법만 LLM(`briefing_learner`)에 맡긴다. 노트가 모두 있으면 LLM을 부르지 않는다.
5. 브리핑에 `l1_sources`(문법별 출처: `reviewed` / `draft` / `llm`)를 붙이고, 화면이 "선생님 검수", "Claude 초안 · 검수 전", "AI 생성 · 검수 필요"로 나눠 표시한다.
6. 범위: 「한국어 1」 2~4과 문법 7개 × 2개 언어. 대응표에 새 교재 문법을 넣으면 노트도 써야 한다 (테스트가 확인한다).

## 검토한 대안 (Alternatives)
| 대안 | 설명 | 장점 | 기각 이유 |
|---|---|---|---|
| LLM 생성 유지 + "검수 필요" 표시 | 지금 방식 | 데이터 작업 없음 | 틀린 내용을 선생님이 매번 고쳐야 한다. 주 지표(그대로 승인한 비율, 기획 ADR-0020)가 떨어진다 |
| 교재 항목 ID를 키로 | `u03-g02` → 노트 | 대응표가 필요 없다 | 교재마다 같은 문법 노트를 다시 써야 한다. 표준 ID 기준이라는 기획 ADR-0016과 어긋난다 |
| 문법별 노트를 RAG 색인에 넣기 | 검색으로 찾기 | 경로가 하나 | 필요한 문법을 이미 안다. 검색 오차를 들일 이유가 없다 (ADR-0014의 필터 경로와 같은 이유) |
| 학생별로 저장 | 학생마다 노트 | 학생 맞춤 | 같은 내용이 학생 수만큼 복제된다. 학생 개인 차이는 약점·메모로 이미 다룬다 |

## 결과 / 트레이드오프 (Consequences)
- 좋은 점: 모국어 칸이 매번 같은 내용으로 즉시 나온다. LLM 호출이 하나 줄어 브리핑이 빨라진다.
- 좋은 점: 선생님이 한 번 검수하면 그 뒤로 모든 같은 모국어 학생에게 정확한 내용이 간다.
- 대가: 학생 개인의 약점에 맞춘 실수 설명은 노트에 없다. 약점은 구성안의 복습과 팁(LLM)으로만 반영된다.
- 대가: 영어권 노트는 검수할 사람이 없어 당분간 "Claude 초안"으로 남는다.
- 대가: 과를 늘릴 때마다 노트를 써야 한다. 1권 전체(20과) 문법이면 약 40개 × 2개 언어다.

## 재검토 조건
- 선생님이 노트 내용을 자주 고친다면 → 화면에서 노트를 바로 고치고 저장하는 기능을 둔다 (지금은 JSON 파일을 고친다)
- 학습자 모국어가 늘면 → 언어 키만 추가한다. 노트가 없는 언어는 LLM 생성으로 떨어진다
